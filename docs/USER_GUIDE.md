# 操作ガイド

接続せず`examples/sequence.json`を開くとグラフ操作を試せます。
左は機構一覧、中央はチャートと表、右は選択機構の設定です。右側はスクロールできます。

| 操作 | 結果 |
|---|---|
| 点をドラッグ | 時間と変位を変更 |
| 線分を上下へドラッグ | 傾きと時間を維持して両端を移動 |
| 空白／Shiftを押してドラッグ | 時間カーソルを移動 |
| Esc | ドラッグを取り消す |
| 元に戻す | Undo |
| 動作確認モード | 点を編集せず時刻を移動 |

縦軸の上下限を超えてドラッグできます。表の入力は「グラフを更新」で適用します。
点の間は直線補間です。距離はmm、角度は度。拘束は絶対値、直接移動・回転は登録時からの変化量です。

Solid Edgeに接続し、機構ごとに駆動先を登録します。CADで部品を選択して候補を絞り、
強調表示で対象を確認してください。「Solid Edgeへ反映」をオンにすると現在時刻の値を反映します。
拘束にX/Y/Zは使用しません。直接駆動はアセンブリ座標のX/Y/Zです。

変更は「この機構の割り当てを解除」で行えます。接続と他の機構は保持します。
JSON読み込みには全体の切断が必要です。保存するのはグラフで、CADの割り当ては含みません。

動かないときは、接続先アセンブリ、登録、「Solid Edgeへ反映」を確認します。
下部に登録数と反映状態が出ます。閉じたモデルへは再接続・再登録してください。
ログ：`%LOCALAPPDATA%\MechCue\Logs\addin-log.txt`。

## 現在値を読み込む

CADで部品を選び「CADで選んだ部品から候補表示」を押します。
候補が1つなら現在値を選択グラフの全点へ設定します。各点の時刻は変えません。
複数候補なら対象を選び「現在値を読み込み全点に設定」を押してください。
このボタンは候補一覧から選んだ対象にも使えます。変更は「元に戻す」で戻せます。
距離はmm、角度は度、部品座標は選択軸の絶対座標です。
相対移動・回転は未登録なら現在姿勢を基準とする0、登録済みなら登録時からの変化量です。
相対回転の読み込みは-180～180度の範囲です。部品は登録前に現在値を読み込むと急な移動を防げます。

## 固定部品を座標で動かす

「部品座標」とX/Y/Zを選び、部品から現在値を読み込んで登録します。
グラフの値が選択軸の絶対座標 [mm] になります。他の軸・姿勢は登録時のままです。
自由部品、または固定拘束があるトップレベル部品が対象です。
部品座標では、固定拘束以外の拘束があっても登録できます。他の拘束は抑制・削除せず保持します。
固定拘束がなく他の拘束がある部品は、拘束の距離・角度を使用してください。
固定拘束は登録中に抑制します。割り当て解除・切断・通常終了で元の姿勢と抑制状態を復元します。
強制終了では復元できないため、CADを保存する前に復元状態を確認してください。

## 干渉したら停止

「干渉したら停止」をオンにして「Solid Edgeへ反映」を有効にします。
再生、時間カーソル、グラフ編集による反映時に、アセンブリの全部品集合を自身と比較します。
サブアセンブリはSolid Edgeの干渉APIが内部部品へ展開して判定します。
干渉または干渉の可能性を検出したら停止して部品名を表示し、直前の姿勢へ戻します。
チェック済みの直前時刻がある場合はカーソルも戻します。
初期姿勢が干渉する場合、解析が未完了の場合、APIが失敗する場合も停止します。
干渉体積の部品やレポートファイルは作成しません。除外ペア・初期干渉の無視は未対応です。
更新姿勢間の連続的な干渉判定ではありません。速度を下げても見逃し防止を保証しません。
大型モデルではチェックに時間がかかります。安全制御や実機の保護装置としては使用しないでください。

## 複数変数の重ね表示

初期表示は「重ねて表示」です。機構一覧のチェックでグラフに表示する変数を選びます。
チェックを外しても駆動先の登録・再生への反映は維持されます。表示だけを切り替えます。
機構一覧、またはグラフ上部の色付き凡例をクリックして編集対象を選びます。
選択中の線を太く表示し、その点・線分だけをドラッグ編集できます。
距離/座標/移動は左軸 [mm]、角度/回転は右軸 [°] を共有します。
同じ単位で値の範囲が大きく異なる場合、見たい変数だけをチェックしてください。
非表示の変数は縦軸範囲の計算から除外します。時間カーソルは共通です。
「重ねて表示」をオフにすると従来の個別グラフ表示に戻ります。
表示設定は画面内で保持し、グラフJSONには保存しません。

## ドラッグ操作と一定値のグラフ

点・線分の通常ドラッグは上下方向だけです。Ctrlを押した状態でドラッグを開始すると、時間方向も動かせます。
線分のCtrlドラッグでは両端の時刻と値を同じ量だけ移動し、傾きと所要時間を保ちます。
隣の点と時刻が入れ替わらない範囲で移動します。Shiftは従来どおり時間カーソルの操作です。
一定値、またはほぼ一定値のグラフは、前後に最低10mm／10度、現在値の絶対値の10％以上の縦軸余裕を設けます。
例：215.9mmなら約194.3～237.5mmです。通常の変化があるグラフは従来の自動範囲です。
アドインコマンドにはグラフと時間カーソルを描いたアイコンを追加しました。更新後はSolid Edgeを再起動してください。

## 表示チェック・変更単位・最小表示

機構一覧のチェック欄をクリックすると表示だけを切り替えます。名前をクリックすると編集対象だけを切り替えます。
「ドラッグ変更単位」は初期値0.1です。点は値を指定単位へ丸め、線分は移動量を指定単位へ丸めて傾きを維持します。
0を指定すると丸めなしです。数値表からの入力値やCADから読み込む値は、この丸めの対象外です。
変更単位は画面全体で共通です。設定はJSONへ保存しません。
「最小表示」ではグラフ・凡例と再生/停止、時刻、速度、繰り返し、CAD反映、干渉チェックを表示します。
グラフの点の編集は無効になり、クリック/ドラッグで時刻を操作します。再生前に設定を完了してください。
「編集画面へ戻る」で機構一覧・設定・数値表と元のウィンドウサイズへ戻ります。切替時に再生は停止します。

## 再生・コマンド・表示言語

グラフの終点で再生を押すと、最初の点の時刻へ戻って再生します。途中では現在の時刻から再開します。
ボタン名を短くし、主要操作にアイコンを付けました。ボタンへマウスを置くと詳しい説明が表示されます。
「言語」は「自動 / Auto」「日本語」「English」から選べます。自動はWindowsユーザーの表示言語が日本語なら日本語、それ以外は英語です。
指定はユーザーごとに保存され、次回の起動にも適用されます。機構名やCADの部品名、保存済みグラフのデータは変更しません。
アドインメニューの言語変更を反映するにはSolid Edgeを再起動してください。
表示文字列とコマンドの説明をLocalization内のJSONへ分離しています。将来の言語追加では翻訳辞書と選択肢を追加する構成です。

## アセンブリ内の保存と駆動先の復元（alpha.13）

「CAD保存」はグラフ、駆動先、軸、基準値・姿勢、固定拘束の元の抑制状態、速度、繰り返し、干渉チェック、重ね表示、表示チェック、ドラッグ変更単位をアセンブリ内に保存し、Solid Edgeのファイルも保存します。
保存時には再生・CAD反映を止め、基準姿勢と固定拘束の元の状態に戻します。現在の再生時刻や再生中の姿勢を保存する機能ではありません。
Solid Edge側の保存操作でも設定を反映します。編集でファイルを変更状態にするため、保存操作を行ってください。
アドインを閉じたり切断した場合、変更設定をアセンブリ内へ反映しますが、その後にSolid Edgeでファイルを保存する必要があります。
読み取り専用ファイルには保存できません。保存失敗時は表示し、閉じる場合は保存せず閉じるかを選べます。

次回接続時、アセンブリ内の設定があれば自動で読み込み、駆動先も復元します。時刻は0、再生とCAD反映はオフです。
読み込みだけでは部品を動かしたり固定拘束を抑制したりしません。CAD反映をオンにすると駆動を開始します。
駆動先は部品の参照キー、拘束のMechCue専用GUID属性で識別します。名前や一覧番号での推測割り当ては行いません。
削除、置換、属性IDの重複、固定拘束の変更などで特定できない機構は「要再割り当て」と表示し、未登録として残します。
候補を確認して「登録・変更」を行うか「解除」で保存済み割り当てを消してください。復元できない割り当て情報も再保存時に保持します。
アドインのバージョンに対応していない保存形式は読み込みを拒否し、自動で上書きしません。

外部の「JSON保存」「開く」は従来どおりグラフのみです。アセンブリ内部保存の設定とは用途が異なります。
表示言語は引き続きユーザーごとのPC設定です。独立版でも接続後はCAD保存と自動復元を利用できます。

### 実機での画面操作の確認手順

1. Solid Edgeを終了してalpha.13を導入します。普段のモデルのコピー、または新規テスト用アセンブリを開きます。
2. MechCueを開き、距離拘束または角度拘束を登録して、グラフの値と再生速度を変更します。
3. 「CAD保存」を押します。再生とCAD反映がオフになり、部品が基準姿勢へ戻ることを確認します。
4. アドインとアセンブリを閉じ、ファイルを開き直してMechCueを開きます。グラフ、速度、駆動先を確認します。
5. CAD反映をオンにし、復元した駆動先が動くことを確認します。
6. 再度グラフを変更し、Solid EdgeのCtrl+Sで保存します。閉じて開き直し、変更値が復元することを確認します。
7. 「名前を付けて保存」でも設定が引き継がれること、Solid Edgeを再起動しても復元することを確認します。
8. 固定部品の座標駆動でも同様に確認します。読込時には固定状態が変わらず、駆動後の解除で元へ戻ることを確認します。
9. テストモデルで駆動対象を削除した場合、該当軸だけが「要再割り当て」になり、別の対象へ勝手に割り当てられないことを確認します。

開発用APIテストは --persistence-integration-test です。ローカルにインストールされたSiemens Fourbar教材を専用ディレクトリへコピーし、新規アセンブリも生成します。元のモデルは保存せず、元のアクティブ文書へ戻します。教材を配布物に含めません。
