# 操作ガイド

接続せず`examples/sequence.json`を開くとグラフ操作を試せます。
左は機構一覧、中央はチャートと表、右は選択機構の設定です。右側はスクロールできます。

| 操作 | 結果 |
|---|---|
| 点をドラッグ | 時間と変位を変更 |
| 線分を上下へドラッグ | 傾きと時間を維持して両端を移動 |
| 空白／Shiftを押してドラッグ | 時間カーソルを移動 |
| Esc | ドラッグを取り消す |
| 元に戻す | Undo |
| 動作確認モード | 点を編集せず時刻を移動 |

縦軸の上下限を超えてドラッグできます。表の入力は「グラフを更新」で適用します。
点の間は直線補間です。距離はmm、角度は度。拘束は絶対値、直接移動・回転は登録時からの変化量です。

Solid Edgeに接続し、機構ごとに駆動先を登録します。CADで部品を選択して候補を絞り、
強調表示で対象を確認してください。「Solid Edgeへ反映」をオンにすると現在時刻の値を反映します。
拘束にX/Y/Zは使用しません。直接駆動はアセンブリ座標のX/Y/Zです。

変更は「この機構の割り当てを解除」で行えます。接続と他の機構は保持します。
JSON読み込みには全体の切断が必要です。保存するのはグラフで、CADの割り当ては含みません。

動かないときは、接続先アセンブリ、登録、「Solid Edgeへ反映」を確認します。
下部に登録数と反映状態が出ます。閉じたモデルへは再接続・再登録してください。
ログ：`%LOCALAPPDATA%\MechCue\Logs\addin-log.txt`。
