# 操作ガイド

接続せず`examples/sequence.json`を開くとグラフ操作を試せます。
左は機構一覧、中央はチャートと表、右は選択機構の設定です。右側はスクロールできます。

| 操作 | 結果 |
|---|---|
| 点をドラッグ | 時間と変位を変更 |
| 線分を上下へドラッグ | 傾きと時間を維持して両端を移動 |
| 空白／Shiftを押してドラッグ | 時間カーソルを移動 |
| Esc | ドラッグを取り消す |
| 元に戻す | Undo |
| 動作確認モード | 点を編集せず時刻を移動 |

縦軸の上下限を超えてドラッグできます。表の入力は「グラフを更新」で適用します。
点の間は直線補間です。距離はmm、角度は度。拘束は絶対値、直接移動・回転は登録時からの変化量です。

Solid Edgeに接続し、機構ごとに駆動先を登録します。CADで部品を選択して候補を絞り、
強調表示で対象を確認してください。「Solid Edgeへ反映」をオンにすると現在時刻の値を反映します。
拘束にX/Y/Zは使用しません。直接駆動はアセンブリ座標のX/Y/Zです。

変更は「この機構の割り当てを解除」で行えます。接続と他の機構は保持します。
JSON読み込みには全体の切断が必要です。保存するのはグラフで、CADの割り当ては含みません。

動かないときは、接続先アセンブリ、登録、「Solid Edgeへ反映」を確認します。
下部に登録数と反映状態が出ます。閉じたモデルへは再接続・再登録してください。
ログ：`%LOCALAPPDATA%\MechCue\Logs\addin-log.txt`。

## 現在値を読み込む

CADで部品を選び「CADで選んだ部品から候補表示」を押します。
候補が1つなら現在値を選択グラフの全点へ設定します。各点の時刻は変えません。
複数候補なら対象を選び「現在値を読み込み全点に設定」を押してください。
このボタンは候補一覧から選んだ対象にも使えます。変更は「元に戻す」で戻せます。
距離はmm、角度は度、部品座標は選択軸の絶対座標です。
相対移動・回転は未登録なら現在姿勢を基準とする0、登録済みなら登録時からの変化量です。
相対回転の読み込みは-180～180度の範囲です。部品は登録前に現在値を読み込むと急な移動を防げます。

## 固定部品を座標で動かす

「部品座標」とX/Y/Zを選び、部品から現在値を読み込んで登録します。
グラフの値が選択軸の絶対座標 [mm] になります。他の軸・姿勢は登録時のままです。
自由部品、または固定拘束があるトップレベル部品が対象です。
部品座標では、固定拘束以外の拘束があっても登録できます。他の拘束は抑制・削除せず保持します。
固定拘束がなく他の拘束がある部品は、拘束の距離・角度を使用してください。
固定拘束は登録中に抑制します。割り当て解除・切断・通常終了で元の姿勢と抑制状態を復元します。
強制終了では復元できないため、CADを保存する前に復元状態を確認してください。

## 干渉したら停止

「干渉したら停止」をオンにして「Solid Edgeへ反映」を有効にします。
再生、時間カーソル、グラフ編集による反映時に、アセンブリの全部品集合を自身と比較します。
サブアセンブリはSolid Edgeの干渉APIが内部部品へ展開して判定します。
干渉または干渉の可能性を検出したら停止して部品名を表示し、直前の姿勢へ戻します。
チェック済みの直前時刻がある場合はカーソルも戻します。
初期姿勢が干渉する場合、解析が未完了の場合、APIが失敗する場合も停止します。
干渉体積の部品やレポートファイルは作成しません。除外ペア・初期干渉の無視は未対応です。
更新姿勢間の連続的な干渉判定ではありません。速度を下げても見逃し防止を保証しません。
大型モデルではチェックに時間がかかります。安全制御や実機の保護装置としては使用しないでください。
