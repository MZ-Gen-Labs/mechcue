## Maintaining translations

Update the corresponding language edition when changing documentation. Japanese normally uses `.md` and English `.en.md`. Originally English third-party notices and icon-resource notes retain `.md`, with Japanese in `.ja.md`. Do not translate code identifiers or configuration keys.

New public documents need both editions and links to both in this index. Link to the reader's language where a counterpart exists. LICENSE and developer-agent instructions retain their original text. The bug-report template is bilingual.

```powershell
python scripts/Check-Documentation.py
```

The check verifies counterpart coverage, reciprocal navigation, index entries and local targets. It does not prove translation accuracy or external-site availability.
