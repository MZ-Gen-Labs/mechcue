## 物理機能

| 課題 | 内容 |
|---|---|
| BepuPhysicsのベータ版 | 2.5.0-beta.33（公開2026-10-11）を使っている。別プロセスなのでSolid Edgeは巻き込まないが、計算結果の正しさはベータ版に依存する。安定版が出たら移行を検討する。版を変えたら`MechCue.Physics.exe --self-test`で確認する。 |
| 2.4.0の摩擦の原因 | 安定版2.4.0では、摩擦が係数の約1/4にしか効かなかった（加速する板の試験で、摩擦力／重量が0.25）。2.5.0-beta.33では理論値どおり。公開情報で不具合の記録は見つからず、こちらの使い方（コールバックの実装）の問題の可能性も残る。 |
| 静止時の沈み込み | 台の上で静止するワークは、接触ばね（30 Hz）の影響で約0.3 mm沈む。経路検査では、台とワークを許容接触として登録する必要がある。接触の硬さを`RigidBodySetup`で指定できるようにすると、沈み込みを減らせる。 |
| 把持のモデル | 指は位置で動かし、約0.5 mm食い込ませた押し付けと摩擦で把持する。押し付ける力の指定（力で閉じるグリッパー）には未対応。 |
| 反発と形状 | 反発は接触ばねの減衰による弱い近似。衝突形状は構想モデルの箱と円柱だけ。 |
| エンジンの選択 | `IRigidBodyEngine`の口はあるが、計算用プログラムの中でBepuPhysicsに固定されている。設定での切り替えは未対応。 |
| 経路検査の許容接触 | 0.3.3-alpha.02の経路検査で使った許容接触（11組）は、検査のために指定しただけで、アセンブリに保存していない。 |

## 先送りした要望

| 課題 | 内容 |
|---|---|
| 実アセンブリへの物理の適用 | 最初の要望（物理的に検出するボディ・面、つかむ面、ワーク、重力方向を指定する）は、構想モデル`arm5p`で実現した。実際の部品の形状（メッシュ・凸包・複合形状への変換）、面の選択による指定、質量・慣性をSolid Edgeの物理特性から取る処理は未対応。 |
| Solid EdgeのMotion（DDM）の調査 | COM（`Ddmseapi.DDMSEAddin`、ライセンスはMotion Professional）で機構の作成・有効化、重力の読み取りまでは、アセンブリ環境のまま確認できた。機構への部品のマッピングができず（作成した機構の部品が0個）、`Simulate`も未確認のまま、BepuPhysicsへ方針を変えた。Solid Edgeの計算結果と比べる検証用として、再開の余地がある。 |
