# 日時順のリリース一覧

GitHub標準のReleasesページの表示順とは別に、同じバージョン内を「古いもの → 新しいもの」の順に並べた一覧を開けます。日付だけでなく時刻・秒まで比較し、最新を一番下に表示します。バージョン名やタグ、公開状態は変更しません。

## 開き方

1. このリポジトリをPCに配置します。
2. GitHub CLI (`gh`) をインストールし、初回のみ `gh auth login` でログインします。ブラウザーのGitHubログインとは別です。Draftを見る場合はリポジトリの編集権限があるアカウントを使用します。
3. フォルダー内の **Open-Release-List.cmd** をダブルクリックします。
4. ブラウザーで「0.2.0」などのバージョンを選び、一覧の最後にある最新リリースの「アドイン版」または「両版入り」を押します。

バッチファイルを実行するたびにGitHubから最新の一覧を取得します。保存先は `artifacts/release-list/index.html` です。HTMLを再読み込みするだけではGitHubの情報を再取得しないため、更新はバッチファイルをもう一度実行してください。

Draftのダウンロードリンクを開くブラウザーでも、編集権限があるGitHubアカウントにログインしてください。権限がないCLIアカウントでは公開済みリリースだけを取得します。

## 日時の扱い

GitHub GraphQLのリリース `createdAt` を取得し、UTCの日時全体を比較します。表示は日本時間（JST）、秒までです。同じ日時の場合だけタグ名を補助的に使います。異なる0.1.0/0.2.0などは別の一覧に分け、数値として新しいベースバージョンを最初に表示します。

ページをまたぐリリースも取得します。各リリースの添付ファイルは先頭100件まで取得します（MechCueの通常のリリースは5件）。一覧HTMLにトークンは埋め込みません。ただし取得済みDraftの名前・日時・リンクがローカルファイルに残るため、そのHTMLを公開・共有しないでください。

Windows PowerShell 5.1以降とGitHub CLIが必要です。標準ブラウザーで表示します。MechCueやSolid Edgeの起動は不要です。
