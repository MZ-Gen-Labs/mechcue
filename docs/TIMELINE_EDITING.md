# 時間軸とグラフの編集

チャート下部の「＋」「−」で時間軸を拡大・縮小し、「全体」で全時間帯に戻します。右側の横スクロールバーで見えない時間帯へ移動できます。表示範囲は秒数で表示します。フル／最小を切り替えても拡大率と表示位置は維持します。

グラフ上ではCtrl＋マウスホイールで拡大・縮小できます。マウス位置の時刻を基準に拡大します。通常のホイールは横移動です。これらはグラフの点やCAD姿勢を変更しません。新規起動時は全体表示です。

再生中は時刻カーソルが表示範囲の右側へ達したときに表示を送り、カーソルが見える状態を保ちます。開始時、終端での停止、反復で先頭へ戻る場合も追従します。停止中は自由に表示範囲を動かせます。

| 操作 | 動作 |
| --- | --- |
| 点・線分をドラッグ | 値だけを変更 |
| Ctrl＋点・線分ドラッグ | 時刻と値を変更 |
| Alt＋線分ドラッグ | 両端に水平に連続する同じ値の部分もまとめて上下へ移動 |
| Shift＋ドラッグ、空白をドラッグ | 時刻カーソルを変更 |
| Esc、マウスキャプチャ解除 | 途中の編集全体を取り消す |

Ctrl＋Zは元に戻す、Ctrl＋Yはやり直しです。チャートがアクティブな間だけ有効にし、機構名や数値を入力している間は入力欄自身の編集操作を優先します。アドインの編集グループにも「元に戻す」「やり直し」を並べています。対象はチャートのグラフ編集履歴です。

Alt操作では、選んだ線分の左端と同じ値が連続する部分、および右端と同じ値が連続する部分を対象にします。選んだ線分が傾斜していても、両側の水平部分を一緒に動かせます。全対象に同じ変位を加え、時刻と傾斜を保ちます。同値の連続が途切れたところで止まります。値は厳密に同じ場合を対象とします。CtrlとAltを同時に押した場合はAltの上下移動、Shiftも押した場合は時刻カーソル操作を優先します。

チャートの「元に戻す」「やり直す」「最小表示」はアイコンのみで表示し、操作名はツールチップと読み上げ用の名前に付けています。新しいグラフ編集を行うと、それ以前のやり直し履歴は消えます。機構の削除・動作パターンの切り替えでは編集履歴をクリアします。グラフのUndo／Redoは、CAD部品の削除や割り当て変更を取り消すものではありません。機構一覧の削除ボタンは「− 削除」です。

検証は模擬CADと検証用ウィンドウで行います。拡大時の絶対秒数での時刻移動・編集、表示端の制限、ズーム基準点、再生追従、両端の水平部分の連動、繰り返しマウス移動での非累積、取り消し、スクロールUI、フル／最小での表示維持、Undo／Redoと新規編集時の履歴消去を確認します。Solid Edge内での実際のAlt＋マウス操作は更新後の実機確認が必要です。
