# 新しい機構編集画面

この文書は機構編集画面の設計メモです。現在の導入手順は[セットアップ](../Installer/README.md)、操作は[操作ガイド](USER_GUIDE.md)を参照してください。

## 画面

左に機構一覧、中央にタイムチャートと点の数値編集表、右に機構名・駆動方法・駆動先・動作ひな形を表示します。右の設定はスクロールできます。

- **編集**：点の時間・変位をドラッグ編集し、線分全体を上下へ移動。上下限を超える移動も可能です。Shiftで時刻操作、Escで取消。
- **動作確認**：点や線分の上でも時間カーソルだけを動かし、グラフを編集しません。Solid Edgeへ反映がオンのときだけCADへ送ります。
- **元に戻す**：確定したグラフの点編集・表からの変更・ひな形の挿入を戻します。機構の追加、名称・駆動方法変更、CAD駆動先の割当ては対象外です。ファイル読込で履歴をクリアします。
- **移動→保持→戻る**：右側の原点、移動量、片道時間、保持時間から、選択機構のグラフを置き換えます。単位は距離ならmm、角度なら度です。

## CADから割り当て

1. Solid Edgeへ接続します。
2. 右側で駆動方法を選びます。
3. Solid Edgeのパスファインダでトップレベルの部品を1つ選択します。
4. 「CADで選んだ部品から候補表示」を押します。
5. 関連する距離・角度拘束を候補表示します。候補には現在値・単位・取得可能な関連部品名を表示します。
6. 「対象をCADで強調」で対象を確認し、「駆動先を登録」を押します。

「すべての候補を表示」で全体の一覧へ戻せます。面・エッジ、サブアセンブリ内部の部品はこの選択処理の対象外です。CADの選択を常時監視する方式ではなく、ボタンを押したときに読み取ります。部品の直接駆動は従来どおり拘束のある部品を拒否します。

接続中も機構を追加できます。登録済みの機構の駆動方法・軸を変更する場合は「この機構の割り当てを解除」を押します。全体の切断は不要です。独立版とアドイン版の同時駆動は避け、切断してから切り替えてください。

## 確認範囲

両版のビルド、ドラッグ・上下限超過・取消・動作確認モード・往復ひな形・Undo・機構切替の確認、画面の表示を検証しました。部品選択による絞り込みは代替オブジェクトでのテストを確認しました。新しい候補表示・強調の実機操作は未検証です。PLC接続とシリンダーのON/OFFチャートはこの版では未実装です。

## 機構ごとの割り当て変更

駆動先の候補を選び、「駆動先を登録・変更」を押すと、旧対象だけを登録時の基準値へ戻して新しい対象へ変更します。他の機構の登録・グラフ・接続は維持します。「この機構の割り当てを解除」も選択中の機構だけを復元・解除します。同一対象を他の機構が使っている場合は変更を拒否し、旧登録を維持します。割り当て操作では再生を停止し、CAD反映をオフにします。必要に応じて反映を再度オンにしてください。

X/Y/Zの選択は部品の直接移動・回転にだけ適用します。距離・角度拘束では軸選択を無効にしています。距離拘束のOffsetは選んだ面の向きで決まる値であり、グローバルX/Y/Zによる候補の自動絞り込みは行いません。
