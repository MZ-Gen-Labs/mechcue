# 図面の自動構成と主要寸法

0.2.0-alpha.8から、保存済み3Dモデルの図面をMCPで作成できます。概略アセンブリ、箱、板、単純円筒、段差形状、円形穴を持つ部品が主な対象です。

## MCPコマンド

| コマンド | 用途 |
|---|---|
| `solidedge_plan_drawing` | 正面候補・理由・モデル外形・推奨ビューを取得。読み取り専用 |
| `solidedge_list_drawing_views` | アクティブシートのビュー方向、縮尺、モデルリンク、寸法値・状態を取得 |
| `solidedge_auto_drawing` | 保存済みのアクティブ3Dモデルから新規図面を作成し、指定の新規DFTへ保存 |
| `solidedge_complete_drawing` | 既存図面の指定ビューを正面として、足りない投影ビュー・等角図・寸法を追加。保存は別コマンド |
| `solidedge_dimension_drawing_view` | 指定した既存ビューに主要寸法を追加。保存は別コマンド |

`frontOrientation` は `auto/front/back/top/bottom/right/left`。モデルの標準座標での方向です。自動選択で `top` を選んだ場合、その方向を図面の正面として扱います。既存図面では指定モデルの最初の標準投影ビュー、MechCue概略モデルでは正面(-Y)、一般部品では円筒面の軸方向または外形の投影面積を優先します。一般のアセンブリは外形から推奨します。形状だけでは設計意図を確定できないため、方向を明示して変更できます。

正面から第三角法の上側・右側投影を追加します。単純な単一円筒を軸方向から見る場合は、重複する右側ビューを省略します。等角図は `includeIsometric=false` で省略できます。新規図面は用紙に応じて縮尺と配置を決め、等角図は小さい縮尺にする場合があります。既存図面の補完では既存レイアウトを維持し、用紙の端へ達する場合に警告します。

## 寸法の範囲

- `dimensionMode=overall`：正面の幅・高さと、上側投影の奥行き。円筒端面では直径を使用。
- `dimensionMode=features`：外形に加えて、投影された全円の直径、円中心の端面からの距離、主要な直線段差を追加。
- `dimensionMode=none`：ビューのみ作成。

寸法は投影線・円の参照に関連付けた、Solid Edgeの参照寸法です。数値の表示を上書きする方式ではありません。直径は同じビュー・同じ径で一つにまとめ、円位置は最大4か所、段差は各方向の主要なものを選びます。段差の同一方向・同一長さの重複をビュー間で減らします。自動作成した寸法には識別属性を付け、再実行時に重複を防ぎます。手作業で追加した寸法の重複判定は含みません。

寸法線を外側の段に並べ、円径の文字位置を調整します。複雑な形状、文字の大きさ、会社の図面テンプレートによっては手動調整が必要です。線や円を特定できない場合、参照寸法の値が想定と合わない場合などは追加せず、結果の `warnings` に理由を返します。モデルのエッジが削除・分割される更新では参照切れを確認してください。

断面図・詳細図の自動選定、隠れた内部形状の完全な寸法化、幾何公差・はめあい・表面性状・製造基準の決定は含みません。構想用図面としてレビューしてください。

## 利用例

AIには「開いているガントリーの主要寸法付き図面を新規作成して」「正面方向を右側にして図面化して」「この図面の1番のビューを正面として必要なビューと寸法を追加して」と指示できます。

新規作成では3Dモデルを保存してから実行します。`outputPath` は既存ファイルと重ならない絶対DFTパス、`templatePath` は任意のDFTテンプレートです。モデルビューを含まないテンプレートを使用し、A3以上の横向きを推奨します。未保存変更のある3Dモデルを自動保存せず、作成を中止します。作成中に失敗した場合は、確認用に途中の図面を開いたまま残します。

図面追加・作成にはMCPトレイの「作成・編集」が必要です。図面構成の提案・一覧取得には「読み取り・選択」を利用できます。

## 検証

通常のビルドで方向選択、ビュー省略、縮尺計算、入力検証、MCPプロトコルを確認します。Solid Edge 2026を起動して、作成・編集モードで次を実行すると、新規テストフォルダーに部品・図面を生成して実機検証します。

```powershell
python scripts/Test-DrawingNative.py --mcp artifacts/0.2.0-alpha.8/mcp/MechCue.Mcp.exe --output C:/CAD/FreshDrawingTest
```

既存ユーザーデータの形状は変更せず、テスト部品・図面を別途生成します。テスト文書は確認用に開いたまま残します。寸法値、円筒のビュー省略、追加の重複防止、既存図面の補完、アセンブリ更新への追従を確認し、`result.json`へ記録します。

APIの根拠：[DrawingView](https://support.industrysoftware.automation.siemens.com/trainings/se/107/api/SolidEdgeDraft~DrawingView_members.html)、[寸法コレクション](https://support.industrysoftware.automation.siemens.com/trainings/se/107/api/SolidEdgeFrameworkSupport~Dimensions_members.html)。実機の引数と定数はSolid Edge 2026の型定義で確認しています。
