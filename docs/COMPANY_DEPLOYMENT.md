# 会社での導入・セキュリティ確認

MechCueはSolid Edge 2026を時間・変位グラフで制御するWindows x64向けプロトタイプです。
発行元表示はMZ-Gen-Labs、ソースコードはMITライセンスで公開しています。

## 配布方式

0.1.0-alpha.4から、独自の自己展開セットアップをInno Setupへ変更しました。
同じ発行元のWebRevisionDeskでも使用している形式です。必要ファイルを明示して同梱し、
Windows標準のアプリ一覧から削除できます。ランタイムの自動ダウンロードや、
セットアップからのPowerShell・バッチ実行はありません。

セットアップとアプリは現時点ではAuthenticode未署名です。
発行元の文字列表示は電子署名とは異なり、発行元の真正性を証明しません。
新しい形式でも会社のダウンロード制限、ウイルス検出、実行制限に対応できる保証はありません。
アルファ版の表記は開発段階を示します。判定を回避するための名称変更は行いません。

## 管理者権限と変更範囲

Solid Edgeでアドインを認識させるため、管理者権限でProgram Filesへ配置し、
HKLMのSoftware\Classesに以下のCOM登録を作成します。

- CLSID: `{79B86022-7C7D-4768-A3A7-CF8EBD1F7826}`
- ProgID: `MechCue.TimeChartAddIn`
- アセンブリ環境: `{26618395-09D6-11D1-BA07-080036230602}`

Windowsのアンインストール情報もHKLMへ作成します。
サービス・ドライバー・定期実行タスクは作成しません。
CADへの接続と値の更新は、利用者が起動した画面から実行します。
設定・ログは利用者のローカル領域、グラフJSONは利用者が指定した場所へ保存します。
Solid Edgeと.NET 8 Desktop Runtime x64は別途必要です。

## IT担当者に確認する情報

ダウンロードURL、対象ファイル名、警告文、遮断した製品名、発生時刻を確認してください。
ダウンロード時点の遮断か、保存後・実行時点の遮断かによって調査先が変わります。
ReleaseのSHA256SUMS.txtでファイルの同一性を確認できます。
必要に応じて公開ソース・この説明・配布物を会社の正式な審査手順に提出してください。
許可が必要な場合は、会社のIT担当者が適切な配布先や許可ルールを決定します。

今後の配布改善として、有効なコード署名証明書によるEXE/DLLの署名を検討します。
証明書取得や署名サービスの契約が必要で、署名だけで全ての制限が解消するとは限りません。
