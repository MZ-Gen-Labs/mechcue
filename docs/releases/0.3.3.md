# MechCue 0.3.3（作成中）

> 正式版の公開前に、版・検証結果・既知の制限を見直してください。現在は0.3.3-alpha.01〜04の内容をまとめた下書きです。

Solid Edge 2026向けの構想検討・動作確認ツールです。0.3.3では、ロボットアームのピック＆プレースで、ワークの動きを剛体物理で計算できるようにしました。

## 0.3.2からの主な変更

### 剛体物理によるワークの動き
- 構想モデル`arm5p`を追加しました。5軸ロボットアーム（`arm5`）に、指のスライド軸`F1`・`F2`と、ワークの自由物体軸`WX`・`WY`・`WZ`・`WRZ`・`WRY`・`WRX`を加えたものです。`arm5`は変わりません。
- 腕と指のキーフレームから、ワークの動きを剛体物理エンジン（BepuPhysics 2）で計算します。指の摩擦による持ち上げ・滑り、離したときの落下・滑り・転倒を扱います。重力方向・質量・摩擦・床の高さを指定できます。
- MCP：`solidedge_simulate_concept_rigid_body`（Solid Edge接続不要）を追加しました。
- `arm5`向けの幾何学的な計算`solidedge_simulate_concept_physics`（摩擦・転倒なし）は廃止しました。`arm5p`と剛体物理を使ってください。MCPは116ツールです。

### 物理トラック
- `arm5p`のタイムチャートでは、ワークの6軸を**物理トラック**として、指令するトラック（腕・指）と分けて表示します。凡例に「（物理）」と付き、点線で描きます。
- 物理トラックは読み取り専用です。点のドラッグ、表での数値編集、名前の変更、MCPからの直接編集はできません。
- 腕・指のキーフレームや物理の設定を変えると「物理：要再計算」になり、約0.7秒後に自動で再計算します。「物理を再計算」ボタンで手動でも計算できます。「自動」のチェックで自動再計算を止められます。
- 物理の設定と計算結果はアセンブリに保存し、動作パターンごとに最新かどうかを判定します。構想モデルから詳細アセンブリへの設定の移行でも保持します。
- MCP：`mechcue_set_physics`、`mechcue_recompute_physics`を追加し、`mechcue_get_state`で物理の状態（`physics`、各トラックの`derived`）を返します。

### 物理の精度（0.3.3-alpha.04）
- 接触の硬さを指定できるようにし（`contactHz`、既定120 Hz）、台の上で静止したワークの沈み込みを約0.3 mmから約0.02 mmに減らしました。
- 指を力で閉じられるようにしました（`gripForceN`、指1本あたりのN）。グラフの指の値は目標になり、指はワークで止まって、指定した力以下で押し付けます。指定しない場合は従来どおり、指はグラフの値どおりに動きます。
- 反発係数（`restitution`）どおりに跳ね返るようにしました（ぶつかる速さ0.1 m/s未満では跳ね返りません）。
- 接触に余白（`contactSkinMm`、既定0.05 mm）を設け、静止したワークがCAD上で台に重ならないようにしました（Solid Edgeはわずかな重なりも干渉と判定するため）。
- 経路検査で、接したまま動く組（隣り合うリンクなど）を細分化し続けて先へ進まない問題を直しました。このような組は「未確認」とし、許容接触への登録を促します。
- 物理の設定が増えたため、保存済みの物理トラックは「要再計算」になり、自動で計算し直されます。
- BepuPhysics 2.4.0で摩擦が1/4になった原因を特定しました（多点接触の摩擦の上限が1点分の法線力になるライブラリ側の不具合）。引き続き2.5.0-beta.33を使います。

### 計算の別プロセス化
- 物理エンジンを計算用プログラム`MechCue.Physics.exe`に分けました。アドイン版でも、Solid Edgeのプロセスには物理エンジンを読み込みません。計算が異常終了・時間切れ（120秒）になっても、MechCueとSolid Edgeは動き続けます。

## インストール

Windows x64、Solid Edge 2026、.NET 8 Desktop Runtime x64が必要です。

- セットアップ：`MechCue-0.3.3-Setup.exe`（独立版・MCPサーバーは選択式）。
- 独立版ZIP、MCP ZIPと`SHA256SUMS.txt`も配布します。

更新前にSolid Edgeを終了してください。更新後は、AIアプリ側でMCPの接続を再開してください。

## 検証と対応範囲

- 共通ビルド：アプリの自己検査・画面検査（物理トラックの画面検査を含む）、計算用プログラムの試験（静止、自由落下、斜面と加速する板の摩擦、転倒、指による持ち上げと滑り、プロセス境界）、MCPの各検査。
- Solid Edge 2026実機：`arm5p`のピック＆プレースの計算とタイムチャートへの適用、独立版での別プロセス計算。0.3.3-alpha.03をインストールした状態で、アドイン版の別プロセス計算（Solid EdgeにBepuPhysicsを読み込まないこと）を確認しました。

既知の制限：
- 衝突形状は構想モデルの箱と円柱だけです。CADの実形状での接触解析ではありません。
- 力で閉じた指（`gripForceN`）はワークで止まりますが、CADの再生はグラフの値で指を描きます。
- 物理エンジンはBepuPhysics 2.5.0のベータ版です。
- 実際の部品形状を使った物理計算には対応していません。

NC加工・切削・TCP・PLC接続・負荷計算には対応しません。
