# MechCue 0.3.0-alpha.05

MCP通信モニターの一覧を、新しい通信が上に流れる表示へ変更しました。Draft / Prereleaseで配布します。

- 最新のイベントを先頭に表示し、古い通信は下へ移動します。
- 新しい通信が届くと、先頭イベントを自動選択し、JSON詳細も更新します。一覧が下へスクロールされていても先頭へ戻します。
- 表示を一時停止した間は、選択した過去の通信と詳細を保持します。再開すると最新を表示します。
- 検索時も該当する通信を新しい順に表示します。

## 更新手順

MCPを含めてインストールを更新し、タスクトレイのMCP通信モニターを開いてください。

## 検証

最新の先頭表示と自動選択、JSON詳細の更新、古い行が下へ移動すること、一時停止中の選択保持、再開時の最新表示をモニターの画面で検証しました。MCP通信と共通ビルド・インストーラー検査も実行しています。
