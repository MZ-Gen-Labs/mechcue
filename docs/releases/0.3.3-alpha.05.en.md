# MechCue 0.3.3-alpha.05

Latest development release in the 0.3.3 series. Alpha releases remain draft prereleases.

## Changes

- Use simulated force-limited finger positions for CAD playback and path inspection while preserving commanded keyframes. Plot actual positions as dashed overlays.
- Add the physics results window and persist events and warnings in the UI, MCP `physics.report` and CAD settings.
- Capture planar convex solids from real assemblies: 2–128 top-level parts, one free workpiece and fixed surroundings. Obtain mass from CAD material density and volume; compute uniform-density inertia from convex geometry. See [scope and workflow](../CONVEX_PHYSICS.en.md).
- Edit Solid Edge Simulation loads and fixed conditions, and delete individual conditions. Read back edits and restore on failure.
- Provide 119 MCP tools. Include alpha.03–04 improvements: a separate physics process, contact stiffness, force-limited fingers, restitution, contact skin and sliding-contact inspection progress fixes.
- Default the GitHub landing page to English with an English/Japanese switch. Include bilingual guides and development records.

## Downloads

Requirements: Windows x64, Solid Edge 2026 and .NET 8 Desktop Runtime x64. Close Solid Edge before updating and reconnect the AI client's MCP session afterwards.

- `MechCue-0.3.3-alpha.05-Setup.exe`: add-in installer with optional standalone and MCP components.
- `MechCue-0.3.3-alpha.05-win-x64.zip`: standalone application.
- `MechCue-0.3.3-alpha.05-MCP-win-x64.zip`: MCP server.
- `SHA256SUMS.txt`: SHA-256 checksums.

## Validation and limitations

The common build checks application logic and UI, the physics engine, 119 MCP tools and transport, COM declarations, and installer inputs/version/checksum. These automated checks do not install the product or operate CAD.

Previously recorded Solid Edge 2026 development-build checks (2026-10-23) cover a 20-part convex assembly, a material-derived mass of 7.833 kg, no native workpiece/support interference, continuous path verification for all 190 pairs over 0–4 seconds, and chart persistence across reconnection. This release has not been installed and rechecked on CAD hardware.

Curved/concave/hollow shapes, nested assemblies, multiple materials, direct CAD inertia tensors, and inference of mechanism/gripper motion from real assemblies remain unsupported. The engine is BepuPhysics 2.5.0-beta.33. NC/cutting/TCP/PLC/load calculations remain outside scope.
