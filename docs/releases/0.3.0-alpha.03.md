# MechCue 0.3.0-alpha.03

Solid Edgeと同じ1～10のメッシュスライダー指定をMCPに追加しました。Draft / Prereleaseで配布します。

- `solidedge_create_simulation_study` の既定値を `meshLevel=5` に変更。1が粗く、10が細かい指定で、形状からサイズを自動計算します。
- `solidedge_run_simulation` に `meshLevel` を追加。0は現在の設定を保持します。
- 解析一覧と実行結果に、スライダーの細かさ `meshLevel` と実際の全体サイズ `meshSizeMm` を表示します。
- 従来のmm指定も保持。作成時の正の `meshSizeMm` はスライダーより優先し、実行時は両方の正の値を同時に指定できません。

## 指示例

「メッシュの細かさを8にして、アラートを抑制して再生成・解析してください」

`meshLevel=8, regenerateMesh=true, suppressAlerts=true` を指定します。MCPを更新後、接続を再起動してください。

## 検証

Solid Edge 2026で200×30×10 mmの新規テスト部品を作成。ネイティブスライダーの1で40 mm、既定値5で20 mm、10で4 mmに自動計算されることを確認しました。10での再生成と200 Nの線形静解析が成功し、相当応力約80.74 MPa、最大変位約1.059 mmでした。

範囲外の指定と二重指定はCAD操作前に拒否します。設定値の直接返却だけでなく、ネイティブAPIの読戻しと解析で確認しています。
