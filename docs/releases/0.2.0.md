# MechCue 0.2.0

Solid Edge 2026向けの、構想検討・動作確認用の正式版です。0.2.0-alpha.12の機能を正式版としてまとめています。

## 0.1.0からの主な変更

- MCPからSolid Edgeの基本操作：オーダードの押し出し・切り抜き、アセンブリへの配置・移動・平面拘束、文書保存、図面作成・PDF出力。
- 3/4/5軸工作機械とガントリー型搬送装置の概略モデルをゼロから生成。概略軸をタイムチャートへ一括登録。
- 複数の動作パターンを名前付きで保存・切り替え。グラフやCAD保存に全パターンを保持。
- 図面の正面方向候補、必要な投影ビュー、外形・穴径・穴位置・段差の主要寸法を作成。
- 穴位置寸法の重複防止。同じビュー・方向・基準の同じ位置は1つに集約。旧版のMechCue重複寸法も整理可能。
- 3Dモデルへ外形・厚さ・円径・位置・段差・対応する傾斜角の参照PMIを追加し、モデルビューで表示を切り替え。
- MCPのアクセス許可をタスクトレイから切り替え。設定アイコンはインストール完了後・Windowsログイン後に自動起動。
- アドインメニュー、コンパクト表示、パネルサイズ変更、再生・一時停止、診断ログなどを改善。

## インストール

Windows x64、Solid Edge 2026、.NET 8 Desktop Runtime x64が必要です。

- 通常：`MechCue-0.2.0-Setup.exe`。独立版とアドイン版を含みます。
- アドイン専用：`MechCue-0.2.0-AddIn-Setup.exe`。
- MCPを使う場合は、インストールで「MCPサーバー」を選択してください。
- ZIPでの配布：独立版とMCPを別々に用意しています。

更新前にSolid Edgeを終了してください。MCPとトレイ設定はインストーラーが終了処理を行います。更新後はAI側のMCP接続を再接続してください。設定アイコンの「作成・編集も許可」を選ぶとCAD作成機能を利用できます。

## 対応範囲

- 基本形状と概略機構の作成・動作確認を対象とし、NC加工・切削・TCP・負荷計算は含みません。
- 図面・PMIは形状に関連付いた参照寸法です。製造に必要な全寸法や公差を自動決定するものではありません。
- 図面の穴位置は各ビューで最大8箇所。寸法数の上限も適用します。
- 3D PMIは単一ボディの部品`.par`が対象です。アセンブリ・板金・複数ボディ・自由曲面の完全な注釈は未対応です。
- 幾何公差、データム、表面粗さ、断面・詳細図の自動選定は未対応です。
- 干渉は更新した各姿勢で判定します。更新間の連続的な衝突は保証しません。
- 形状更新で参照辺が消える場合は、寸法・PMIの関連切れを確認してください。
- PMIへの初回アクセスはSolid Edge内部領域の初期化で未保存状態になる場合があります。形状を変えず、`nativePmiInitialized`で報告します。

[図面MCP](../DRAWING_AUTOMATION.md)、[3D PMI](../PMI_AUTOMATION.md)、[MCP接続とアクセス設定](../../Mcp/README.md)に詳細を記載しています。

## 検証

- Solid Edge 2026実機で図面の55項目：方向・ビュー・寸法値・外側への配置・5穴の重複防止・再実行・アセンブリ更新への追従。
- 既存図面の重複除去、異なる基準の同値寸法・手作業寸法の維持を専用図面で確認。
- 3D PMIの14項目：穴付き板・円柱・段差・45度傾斜部品、参照状態、モデルビュー切り替え、保存と重複防止。
- PMIの閉じて再読込した後の復元、厚さ20→25mmへの寸法追従、ユーザーPMIの保持を追加確認。
- 共通処理・画面・MCP通信と許可制御・更新終了・COM定義・両インストーラーのビルドとパッケージ検査。

インストーラー検査はパッケージの生成・構成・更新用ヘルパーを確認するもので、すべてのPC環境での導入・CAD操作を保証するものではありません。Solid Edge 2026の実際の導入・起動・簡単な動作・削除は開発中の配布版で利用者が確認しています。

正式版は公開Releaseとして配布します。アルファ版はこれまでどおり下書きで保持します。
