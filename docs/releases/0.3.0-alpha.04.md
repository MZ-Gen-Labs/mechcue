# MechCue 0.3.0-alpha.04

タスクトレイの設定アプリにMCP通信モニターを追加しました。Draft / Prereleaseで配布します。

- 依頼・通知・結果の時刻、方向、プロセス番号、機能名、成功・失敗、応答時間を一覧表示。
- 選択した通信の引数と結果をJSONで確認。
- 検索、表示の一時停止、一覧クリア、JSON Linesログ保存。
- 「常に手前に表示」と「通信を記録」の切り替え。設定を保持。
- 標準入出力を変更せず、別のローカル記録ファイルから表示。記録失敗時もMCP通信を継続。

## 利用手順

MCPを含めて更新し、AIアプリのMCP接続を再起動してください。タスクトレイのMechCue MCP設定から「MCP通信モニター」を開きます。「常に手前に表示」でSolid Edgeの上に表示できます。

一覧は最新500件、各プロセスは約4 MiB×3世代、定期整理は64ファイル・7日を基準とします。256 KiBを超える単一メッセージはモニターの詳細のみ省略します。ログには引数・結果・ファイルパスが含まれます。

## 検証

実際のMCPプロセス2つにJSON-RPCを送信し、記録された引数・結果の一致、同じ要求IDの分離、UTF-8の分割入力、失敗表示、応答時間を確認しました。記録のオン・オフを実行中に切り替え、記録先に書き込めない状態でも正常に通信することを確認しました。

モニターの表示・検索・詳細、一時停止と再開、常に手前に表示の設定保持を検証しました。CAD操作の変更はありません。
