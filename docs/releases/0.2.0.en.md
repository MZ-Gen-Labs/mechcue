# MechCue 0.2.0

<!-- mechcue-docs-language -->
[日本語](0.2.0.md) | [English](0.2.0.en.md) | [Documentation](../INDEX.en.md)

Stable release for concept studies and motion checks on Solid Edge 2026, consolidating 0.2.0-alpha.12.

## Changes from 0.1.0

- MCP ordered protrusions/cuts, assembly placement/movement/planar constraints, saves, drawings and PDF.
- Generate3/4/5-axis mills and gantries and import all concept axes into charts.
- Named motion patterns retained in graph/CAD saves.
- Front-view suggestions, projected views and principal overall/hole/position/step drawing dimensions.
- Deduplicate equal hole positions for the same view/direction/datum; arrange old generated duplicates.
- Reference PMI for overall/thickness/circle/position/step/supported slope dimensions and model views.
- Tray read/edit permissions, auto-start after setup/login, improved ribbon/compact/panels/play-pause/logging.

Requires Windows x64, Solid Edge 2026 and .NET 8 Desktop Runtime x64. Packages: `MechCue-0.2.0-Setup.exe` (both application forms), `MechCue-0.2.0-AddIn-Setup.exe`, separate standalone/MCP ZIPs and SHA256. Select MCP if needed. Close Solid Edge before updating; setup stops MCP/tray. Reconnect the AI client afterwards and choose create/edit for CAD writes.

## Limits and validation

Concept geometry/motion, not NC/cutting/TCP/load analysis. Drawings/PMI are associated reference dimensions, not complete manufacturing dimension/tolerance decisions. Hole positions are limited to eight per view with overall dimension limits. At this release PMI supports single-body `.par`, not assemblies/standalone sheet metal/multibody/freeform annotation. No GD&T/datums/finish or automatic section/detail selection. Sampled pose checks do not certify intervals. Check broken associations after edge changes. First PMI access can dirty native storage and reports `nativePmiInitialized` without shape change.

Solid Edge 2026 verified55 drawing cases (directions/views/values/lanes/five-hole deduplication/reruns/assembly updates), old duplicate removal while retaining different datums/manual dimensions,14 PMI cases plus reopen/thickness20→25/user-PMI preservation. Common/UI/MCP/access/update/COM and both installers passed build/package checks. These are not installation/CAD guarantees for every PC; user native installation/basic operation/removal had been checked on development deliveries.

Stable releases are public; existing alphas remain drafts. See [drawings](../DRAWING_AUTOMATION.en.md), [PMI](../PMI_AUTOMATION.en.md), [MCP](../../Mcp/README.en.md).
