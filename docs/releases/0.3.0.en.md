# MechCue 0.3.0

<!-- mechcue-docs-language -->
[日本語](0.3.0.md) | [English](0.3.0.en.md) | [Documentation](../INDEX.en.md)

Stable concept-study/motion-check release for Solid Edge 2026, consolidating the0.3.0 alpha series and later chart/MCP fixes.

## Changes from 0.2.0

Timeline zoom/scroll/playback following; Alt-segment movement of adjoining horizontal runs; chart Undo/Redo and focused Ctrl+Z/Y with add-in Redo; drag-reordering/persisted track order and deletion including sample tracks.

One-line toolbar with CAD/Data/View/Settings, review mode renamed View, redraw-suppressed full/compact transitions, saved window bounds and nine-position Ctrl+Alt+Shift plus UIO/JKL/M,. shortcuts. Repeated keys toggle full/compact. Ordinary operations preserve Apply/Collision/Loop; Auto enables Apply on Play and clears on errors.

MCP-opened chart creation now uses the host UI thread and avoids duplicate connection. CAD MCP adds launch/state/safe exit, chart connection, asynchronous saves/polling, multiaxis edits, nested placement/driving, properties/variables and quantity BOM. Native Simulation supports single-part linear-static setup/mesh/results. Assembly inspection/images/static reports, study-video output and traffic monitor were extended. This release had86 MCP tools.

## Installation and checks

Requires Windows x64, Solid Edge 2026 and .NET 8 Desktop Runtime x64. Distributions: `MechCue-0.3.0-Setup.exe`, `MechCue-0.3.0-AddIn-Setup.exe`, standalone/MCP ZIPs and SHA256. Close CAD, select optional MCP and reconnect the AI client after update.

Common checks cover self/smoke/mock CAD,86-tool protocol/access/save/update shutdown, COM/icons and both installers, minimum-width toolbar, focused Undo, reordering/persistence, zoom/follow and Apply retention. Development hardware verified MCP-open/import/five patterns/save/reload and sampled interference. Users verified window shortcuts/mode switching. Newly added Ctrl+Z/Y, ribbon Redo and reordering were tested in mock/windows and still needed post-update hardware checks.

No NC/cutting/TCP/PLC/load analysis. This release's interference is discrete, not continuous/minimum-gap proof. Drawings/PMI assist reference dimensions; Simulation needs a separate native license. Nested driving changes all references to a shared child and requires explicit acknowledgement.

See [timeline](../TIMELINE_EDITING.en.md), [controls](../CHART_MENUS.en.md), [placement](../WINDOW_PLACEMENT.en.md), [Simulation](../SIMULATION_AUTOMATION.en.md), [MCP](../../Mcp/README.en.md). Stable is public; existing alphas remain draft prereleases.
