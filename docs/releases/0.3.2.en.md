# MechCue 0.3.2

Stable concept-study/motion-check release for Solid Edge 2026, consolidating alpha.01–07.

## Changes from 0.3.1

Concept parts now use dimensioned constrained sketches referenced to global planes and symmetric about the origin. Variables `SizeX/SizeY/SizeZ` or `Diameter/Length` can be changed with `solidedge_set_variables` without shifting the part centre. Mill column/saddle initial overlap and mill5 trunnion/table overlap are corrected. Generation checks all linear-travel endpoint combinations. New `arm5` provides J1–J5 plus WX/WY/WZ workpiece movement.

Newly created assembly PMI follows immediately, rather than waiting for save/reopen. `solidedge_add_pmi_distance` adds moving-part position/height/gap dimensions. `recreateGenerated` rebuilds old generated PMI; measured values verify orientation.

Machining adds persistent parallel planes, thread search, hole/thread/pattern editing, dependencies/safe deletion, structured interference pairs/volume and fastening-interface checks. Wrong argument names reject before execution.

`check_motion` accepts `timeBudgetSeconds` (default10), reporting timeout/incomplete rather than misleading clear samples. Sliding/rotating contact pairs require justified AllowedContacts. Playback adds Refine toggle.

MCP child process output no longer contaminates protocol stdout. Variable tools use table names. Session discovery rejects stale records after PID reuse. One setup now offers Standard/Add-in only/Custom, preserving legacy add-in-only defaults and allowing component changes without uninstall. This release has113 MCP tools.

## Installation and validation

Windows x64, Solid Edge 2026 and .NET 8 Desktop Runtime x64. `MechCue-0.3.2-Setup.exe` offers optional standalone/MCP; standalone/MCP ZIPs and SHA256 are also provided. Close Solid Edge before update and reconnect MCP afterwards.

Common self/UI/113-tool protocol/permission/input/COM/setup checks include seven old-install detection cases. Native checks covered five templates/dimension variables/import/save/reopen,28 assembly-PMI follow regressions, regenerated mill3 path, arm5 pick/place carrying path and launch stdio. Main features were also checked with installed alpha.07.

Known limits: old PMI remains frozen until recreation; changing dimension variables does not update manifest `sizeMm`; arm5 carrying requires explicit hand-matched workpiece points and has no IK/finger axes; generation checks do not cover tilted rotary poses; old add-in-only upgrade detection was helper-tested, not actual-install validated.

No NC/cutting/TCP/PLC/load analysis. Inspection is conditional on policy/budgets, not a design-safety guarantee. Stable is public; alphas remain draft prereleases.
