# MechCue 0.3.0

Solid Edge 2026向けの構想検討・動作確認ツールの正式版です。0.3.0のアルファ系列の機能と、その後のチャート操作・MCP接続の修正をまとめています。

## 0.2.0からの主な変更

- タイムチャートの時間軸を拡大・縮小し、横スクロールで表示範囲を変更。再生位置に表示範囲が追従します。
- Alt＋線分ドラッグで、両端に水平に連続する同じ値の部分もまとめて上下移動。
- グラフのUndo／Redo、チャート内のCtrl＋Z／Ctrl＋Y、アドインの「やり直し」。文字・数値入力中は入力欄の操作を優先します。
- 機構名をドラッグして並べ替え、順番を保存。初期機構を含む「− 削除」を追加。
- フル表示の操作欄を1行に整理し、CAD・データ・表示・設定メニューへ集約。「動作確認」を「表示」に改称。
- フル／コンパクト切り替え時の途中描画を抑制。位置・大きさを復元し、Ctrl＋Alt＋ShiftとUIO／JKL／M,.で9か所へ配置。同じキーの再押下でその位置のまま表示モードを切り替えます。
- 反映・干渉・反復の選択を通常操作で保持。「自動」を選ぶと再生時に反映を有効にし、エラー時は自動を解除します。
- MCPから開いたアドイン画面の処理をホストの画面スレッドへ統一し、応答停止と接続時の二重処理を修正。
- MCPにSolid Edgeの起動・状態確認・安全な終了、MechCue接続、非同期CAD保存と完了確認、複数軸の一括編集、入れ子部品の配置・駆動、属性・変数の操作と部品数量集計を追加。
- 単一ソリッド部品の線形静解析、材料・固定・荷重・メッシュ・結果表示をSolid Edge Simulation API経由で操作。
- アセンブリの構造・形状・配置の読み取り、ビュー画像・干渉確認・報告、設計検討用の動画書き出しとMCP通信モニターを拡張。MCPは86ツールです。

## インストール

Windows x64、Solid Edge 2026、.NET 8 Desktop Runtime x64が必要です。

- 両版入り：`MechCue-0.3.0-Setup.exe`。
- アドイン専用：`MechCue-0.3.0-AddIn-Setup.exe`。
- 独立版ZIP、MCP ZIPと`SHA256SUMS.txt`も配布します。

更新前にSolid Edgeを終了してください。MCPを使う場合はインストーラーで「MCPサーバー」を選び、更新後にAI側で再接続してください。

## 検証と対応範囲

共通ビルドでアプリの自己テスト・画面検査、模擬CAD、86ツールのMCP通信・権限・保存・更新終了、COM契約・アイコン資源、両インストーラーの構成を検証します。最小幅の操作欄、Undo／Redo、機構並べ替えと保存後の順番、ズーム・スクロール・再生追従、反映設定の維持を自動検査します。

Solid Edge 2026実機では開発中の版でMCPからの画面起動、5軸取り込み、5動作パターン、保存・再読込、離散姿勢の干渉確認を確認しています。表示位置ショートカットと表示モード切り替えは利用者が動作を確認しました。今回追加したCtrl＋Z／Ctrl＋Y、リボンのやり直し、機構並べ替えは検証用ウィンドウ・模擬CADでの確認であり、更新後の実機確認が必要です。

NC加工・切削・TCP・PLC接続・負荷計算には対応しません。干渉確認は離散姿勢のみで、連続衝突や最小隙間を保証しません。図面・PMIは参照寸法の作成支援です。Simulationは単一部品の線形静解析が対象で、利用可能なSolid Edgeの解析ライセンスが別途必要です。入れ子部品の駆動は共有子文書の全参照に影響するため、明示指定が必要です。
