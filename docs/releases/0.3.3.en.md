## Changes from 0.3.2

New `arm5p` adds finger slides F1/F2 and workpiece free-body WX/WY/WZ/WRZ/WRY/WRX to the unchanged arm5. BepuPhysics 2 computes frictional gripping/slipping, release/fall/sliding/tipping from commanded joints with configurable gravity/mass/friction/floor. MCP `solidedge_simulate_concept_rigid_body` does not need CAD. Old geometric `solidedge_simulate_concept_physics` is removed. MCP has116 tools.

Six workpiece axes are dotted read-only **physics tracks**, labelled Physics. Direct drag/table/name/MCP edits reject. Joint/setup changes mark stale and automatically recompute after about .7 s, with manual Recompute and Auto off available. Settings/results persist by pattern and through concept-to-detail migration. MCP adds `mechcue_set_physics`, `mechcue_recompute_physics` and physics/derived state.

Alpha.04 adds default120 Hz contact stiffness, reducing resting penetration from about .3 to .02 mm; per-finger `gripForceN` force-limited closing toward commanded positions; restitution above .1 m/s impact threshold; default .05 mm contact skin to prevent small native CAD overlap. Sliding-contact inspection no longer refines indefinitely: such pairs remain unverified and prompt contact registration. New setup fields invalidate saved hashes and trigger recomputation. The recorded multipoint-friction issue in2.4.0 motivates continued use of2.5.0-beta.33.

`MechCue.Physics.exe` isolates the engine from the add-in/Solid Edge. Crashes/timeouts(default120 s) report errors while host applications keep running.

## Installation and checks

Requirements: Windows x64, Solid Edge 2026, .NET 8 Desktop Runtime x64. Planned stable filenames: `MechCue-0.3.3-Setup.exe`, standalone ZIP, MCP ZIP and SHA256. These names in draft notes do not establish published assets. Close CAD before updating and reconnect the AI client afterwards.

Common checks cover app/UI including derived tracks, engine/theory and calculator boundaries, and MCP tests. Native checks include arm5p pick/place results/chart application, standalone separate-process calculation and installed alpha.03 add-in isolation with no BepuPhysics loaded into CAD. See [development](../MCP_033_DEVELOPMENT.en.md) for later installed alpha.04 details and [open issues](../OPEN_ISSUES.en.md) for remaining checks.

Limits: collision shapes are concept boxes/cylinders, not real CAD geometry; force-stopped fingers are drawn at commanded graph positions; engine is a2.5.0 beta; arbitrary real-part physical contact is unsupported. NC/cutting/TCP/PLC/load calculations remain outside scope. Alpha releases remain draft prereleases.
