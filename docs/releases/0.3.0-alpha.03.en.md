# MechCue 0.3.0-alpha.03

<!-- mechcue-docs-language -->
[日本語](0.3.0-alpha.03.md) | [English](0.3.0-alpha.03.en.md) | [Documentation](../INDEX.en.md)

Adds native1–10 mesh-level control. **Draft/Prerelease only.**

New studies default `meshLevel=5`, with1 coarse and10 fine, deriving size from geometry. Runtime `meshLevel=0` retains settings. Lists/results show level and actual `meshSizeMm`. Positive absolute mm on creation takes precedence; runtime cannot specify both positive size and level.

Example: `meshLevel=8, regenerateMesh=true, suppressAlerts=true`. Reconnect after MCP update.

Native200×30×10 mm tests read back40 mm atlevel1,20 mm at5 and4 mm at10. Level10 regeneration/200 N solve succeeded with about80.74 MPa and1.059 mm displacement. Invalid ranges/dual values reject before CAD. See [Simulation](../SIMULATION_AUTOMATION.en.md).
