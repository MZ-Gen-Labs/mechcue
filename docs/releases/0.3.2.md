# MechCue 0.3.2

Solid Edge 2026向けの構想検討・動作確認ツールの正式版です。0.3.2-alpha.01〜alpha.07の機能と修正をまとめています。

## 0.3.1からの主な変更

### 構想モデル
- 構想モデルの部品を、寸法付きの拘束スケッチで作るようにしました。グローバル基準平面を参照し、原点を中心に対称の拘束を付けるので、意図しない変形が起きません。寸法には`SizeX`／`SizeY`／`SizeZ`（円柱は`Diameter`／`Length`）の変数名が付き、`solidedge_set_variables`で後から変更できます。部品の中心は動きません。
- 工作機械（mill3／mill4／mill5）で、コラムがサドルと作成直後から干渉していた不具合を直しました。コラムはサドルの移動範囲の外に置き、ベースを延ばしています。mill5のトラニオンと回転テーブルの重なりも直しました。
- 5軸ロボットアーム（`arm5`）を追加しました。テーブルに設置したアームで、J1〜J5の関節と、ワークを運ぶための移動軸WX／WY／WZがあります。グラフで動かせます。
- 生成時の検査で、直線軸の移動範囲の端のすべての組み合わせで部品が重ならないことを確認します。

### PMI
- APIで作ったアセンブリPMIが、作成した直後から部品の動きに追従するようにしました。以前は保存して開き直すまで、値が作成時のまま止まっていました。
- 動く部品どうしの位置・高さ・すきまのPMIを置く`solidedge_add_pmi_distance`を追加しました。
- `solidedge_auto_pmi`に、以前の版で作った生成PMIを作り直す`recreateGenerated`を追加しました。寸法の向きは値で確かめてから付けます。

### 加工フィーチャー・干渉チェック
- 保存後も残る平行基準平面の作成、ねじ規格の検索、穴・ねじ・穴パターンの編集、依存関係の読み取りと安全な削除、干渉ペアと干渉体積、締結寸法の整合確認を追加しました。誤ったMCP引数名は、実行する前に拒否します。
- 経路検査（`check_motion`）は、処理時間の上限（`timeBudgetSeconds`、既定10秒）を指定できます。打ち切った場合は`timedOut`と`verdict: "incomplete"`を返し、干渉なしと誤解されないようにしました。面で接したまま滑る・回る部品の組は、`AllowedContacts`に登録して検査します。
- 再生時の干渉検査の細分化を切り替える「細分」オプションを追加しました。

### MCP・インストーラー
- MCPからSolid Edgeや設定アイコンを起動したとき、通信路（標準出力）に子プロセスの出力が混ざり、AIアプリが応答を受け取れなくなることがある問題を直しました。
- 変数ツールが、Solid Edgeの変数表の名前で読み書きするようになりました。
- 終了した画面の古い記録が、MCPのセッション一覧に残らないようにしました。
- セットアップを1種類にまとめました。インストールの種類で「標準（アドインと独立版）」「アドインのみ」「カスタム」を選べます。以前のアドイン専用版から更新した場合は、独立版を選ばない状態で始まります。構成の切り替えにアンインストールは不要です。
- MCPは113ツールです。

## インストール

Windows x64、Solid Edge 2026、.NET 8 Desktop Runtime x64が必要です。

- セットアップ：`MechCue-0.3.2-Setup.exe`（独立版・MCPサーバーは選択式）。
- 独立版ZIP、MCP ZIPと`SHA256SUMS.txt`も配布します。

更新前にSolid Edgeを終了してください。更新後は、AIアプリ側でMCPの接続を再開してください。

## 検証と対応範囲

共通ビルドで、アプリの自己検査・画面検査、MCP 113ツールの通信・権限・入力検査、COM契約、インストーラーの構成を検証しています。インストーラーの検査には、アドイン専用版からの更新の判定（7通り）も含まれます。

Solid Edge 2026実機では、次の点を確認しています。
- 構想モデル5種類の作成・寸法変数・グラフ取り込み・保存と開き直し
- アセンブリPMIの追従（回帰検査28項目）
- 作り直した3軸機の構想モデルの経路検査
- 5軸ロボットアームのピック＆プレース（ワークの運搬を含む）の経路検査
- MCPからSolid Edgeを起動したときの通信

0.3.2-alpha.07をインストールした状態でも、主な機能の動作を確認しました。

既知の制限：
- この版より前に作ったアセンブリPMIは、`recreateGenerated`で作り直すまで値が止まったままです。
- 寸法変数を変えても、構想の定義ファイルの`sizeMm`は自動では更新されません。
- arm5のワークの運搬は、運ぶ区間の移動軸のキーフレームを手先に合わせて入れる前提です。逆運動学と、指の開閉の軸はありません。
- 回転軸を傾けた姿勢での干渉は、構想モデルを作るときの検査では調べていません。
- 以前のアドイン専用版からの更新は、判定の処理を検査していますが、実際のインストールでは確認していません。

NC加工・切削・TCP・PLC接続・負荷計算には対応しません。経路検査は登録した方針と予算の範囲での確認で、設計の安全を保証するものではありません。
