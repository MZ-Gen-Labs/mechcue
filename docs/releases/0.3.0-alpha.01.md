# MechCue 0.3.0-alpha.01

単一部品の強度・変形解析を操作するMCPを追加しました。アルファ版のため、リリースはDraft / Prereleaseのまま保持します。

## 追加内容

- 単一ソリッド `.par` を対象とする線形静解析・四面体メッシュ。
- 材料一覧・適用、面一覧・選択、解析スタディ一覧・作成。
- 面の完全固定、全体座標の力（N）、面への圧力（MPa）。
- メッシュ生成・解析実行、ミーゼス相当応力（MPa）・変位（mm）の取得と表示。
- 解析成功時の入力照合記録を部品に保存。条件変更後の古い結果は拒否し、再解析を案内。
- 結果表示環境からの新規スタディ作成・別スタディ解析を事前に検出し、Solid Edgeで戻る操作を案内。

## 利用方法

セットアップのMCP項目を選択して更新し、AIクライアントのMCP接続を再起動してください。タスクトレイの設定を「作成・編集」にします。Solid EdgeのSimulation機能・解析ライセンスが必要です。

操作例：部品を開き、材料を設定し、選択した面を固定。荷重面を選択してYマイナス方向に100 Nを設定し、メッシュ3 mmで解析してください。

[詳しい操作・11ツールの一覧](../SIMULATION_AUTOMATION.md)

## 検証

Solid Edge 2026で新規テスト部品（100×10×10 mmの鋼製片持ち梁）を作成し、100 N荷重の最大相当応力約59.95 MPa・最大変位約0.1995 mmを確認しました。変位は梁の計算式と25%以内で一致し、200 Nに変更すると約2倍になりました。材料・面割り当て、複数面への圧力の単位、メッシュのみの実行、結果図の切り替え、条件変更後の古い結果の拒否も確認しています。

テスト部品を保存・閉鎖・再読込みし、解析入力の照合情報と変位結果が復元されることを確認しました。既存のユーザーの部品は変更・閉鎖していません。

共通ビルドではアプリ、55個のMCPツールと権限・入力検証、COM定義、MCP設定・更新、インストーラーを検査します。CAD実機解析はGitHub CIの対象外です。

## 第一段階の範囲

アセンブリ解析・接触・非線形・熱・振動などは未対応です。既存の解析条件の編集・削除はSolid Edgeの画面を使用してください。保存は明示的なCAD保存で行います。解析中のライセンス・ソルバーダイアログはSolid Edge側で確認してください。
