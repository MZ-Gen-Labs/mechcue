# MechCue 0.3.0-alpha.01

<!-- mechcue-docs-language -->
[日本語](0.3.0-alpha.01.md) | [English](0.3.0-alpha.01.en.md) | [Documentation](../INDEX.en.md)

Adds MCP single-part stress/displacement analysis. **Keep this alpha as Draft/Prerelease.**

Single-solid `.par` linear-static tetrahedral studies support material listing/application, face listing/selection, study listing/creation, fixed faces, global force(N), pressure(MPa), mesh/solve and von Mises stress(MPa)/displacement(mm) read/display. Successful input fingerprints persist in the part and reject stale results after changes. Creating/solving another study from results mode rejects before work and asks the user to return to modeling.

Select MCP in setup, reconnect the client and allow edit in the tray. Native Simulation capability/license is required. Example: steel part, selected face fixed,100 N in−Y and3 mm mesh. See the [11-tool guide](../SIMULATION_AUTOMATION.en.md).

Native100×10×10 mm steel cantilever at100 N gave about59.95 MPa and .1995 mm displacement, within25% of beam theory;200 N approximately doubled displacement. Material/face assignments, multi-face pressure units, mesh-only, plots and stale rejection passed. Save/close/reopen retained fingerprints/results; existing user parts were untouched. Common app/55-tool protocol/input/access/COM/tray/update/setup checks passed; native solve is outside CI.

No assembly/contact/nonlinear/thermal/vibration analysis. Edit/delete existing conditions in CAD UI, save explicitly and inspect license/solver dialogs.
