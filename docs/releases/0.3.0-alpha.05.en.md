# MechCue 0.3.0-alpha.05

<!-- mechcue-docs-language -->
[日本語](0.3.0-alpha.05.md) | [English](0.3.0-alpha.05.en.md) | [Documentation](../INDEX.en.md)

Changes the traffic monitor to newest-first display. **Draft/Prerelease only.**

New events go to the first row, automatically selecting/updating JSON detail and scrolling to the top. Older events move down. Pause retains the chosen old event/detail; resume returns to latest. Search results also use newest-first order.

Update MCP and open the tray monitor. UI checks verified first-row insertion/selection/detail, older-row movement, paused selection and resume. Protocol/common build/installer checks also ran.
