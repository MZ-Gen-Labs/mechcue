# MechCue 0.3.0-alpha.02

MCPからSolid Edgeのアラート表示を切り替え、既存メッシュを細かくして再解析できるようにしました。Draft / Prereleaseで配布します。

## 変更

- `solidedge_get_automation_settings` でDisplayAlertsを確認、`solidedge_set_display_alerts` でON/OFFを変更。作成・編集モードが必要です。
- 解析の `suppressAlerts=true` は呼び出し中だけアラートを抑制し、成功・例外時に元へ復帰。
- `regenerateMesh=true` で対象スタディのメッシュを再生成。形状・材料・固定・荷重を保持し、古い結果を無効化します。
- メッシュサイズのAPI単位をmへ修正。alpha.01ではサイズ設定値の表示と実際の細かさが一致しない場合がありました。旧メッシュは再生成してください。
- メッシュ削除時に部品ウィンドウが閉じられるSolid Edgeの動作へ対応。読み込み済みの部品を再表示・アクティブ化します。
- 解析後に対象文書とエラー状態を再確認し、別部品に切り替わった処理を成功として記録しません。

## 利用例

「メッシュを2 mmにして再生成し、アラートを抑制して解析してください」

`solidedge_run_simulation` に `meshSizeMm=2, regenerateMesh=true, suppressAlerts=true` を指定します。セットアップでMCPを更新し、接続を再起動してください。

## 実機確認

Solid Edge 2026の200×30×10 mm鋼製片持ち梁・200 N荷重で、2 mmの再生成後に四面体要素98,778個を確認しました。最大相当応力約81.10 MPa、最大変位約1.059 mmです。従来の粗いメッシュは141要素でした。結果は部品へ保存済みです。

アラートのON/OFF、通常完了・入力エラー時の設定復帰を確認しました。ソルバー・ライセンス側のすべてのダイアログが抑制される保証はありません。
