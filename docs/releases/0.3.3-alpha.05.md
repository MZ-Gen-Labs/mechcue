# MechCue 0.3.3-alpha.05

<!-- mechcue-docs-language -->
[日本語](0.3.3-alpha.05.md) | [English](0.3.3-alpha.05.en.md) | [文書一覧](../INDEX.md)

0.3.3開発系列の最新版。アルファ版は下書きのPrereleaseとして配布します。

## 主な変更

- 力で閉じる指の実位置を物理計算から取得し、CAD再生・経路検査に適用。指令値を保持し、グラフには実位置を破線で表示します。
- 「物理の結果」画面を追加し、物理イベント・警告を画面、MCPの`physics.report`、CAD設定へ保存します。
- 実アセンブリの平面凸多面体を物理計算に取り込みます。トップレベルの2～128部品から自由ワークを1個選び、他の部品を固定物として扱います。材質密度と体積から質量を取得し、凸形状から一様密度の慣性を計算します。[対応範囲と操作](../CONVEX_PHYSICS.md)。
- Solid Edge Simulationの荷重・固定条件の編集と条件単位の削除に対応。編集結果を読み戻し、失敗時は復元します。
- MCPは119ツール。0.3.3-alpha.03～04の物理計算の別プロセス化、接触の硬さ、力で閉じる指、反発係数、接触余白、滑り接触で経路検査が進まない問題への修正も含みます。
- GitHubのトップを英語にし、先頭の「English | 日本語」で切り替えられるようにしました。ガイドと開発文書も日英で収録しています。

## 配布物

Windows x64、Solid Edge 2026、.NET 8 Desktop Runtime x64が必要です。更新前にSolid Edgeを終了し、更新後はAIクライアントのMCP接続を再開してください。

- `MechCue-0.3.3-alpha.05-Setup.exe`：アドイン。独立版とMCPサーバーは選択式。
- `MechCue-0.3.3-alpha.05-win-x64.zip`：独立版。
- `MechCue-0.3.3-alpha.05-MCP-win-x64.zip`：MCPサーバー。
- `SHA256SUMS.txt`：配布物のSHA-256。

## 検証と制限

共通ビルドでアプリの自己検査・画面検査、物理エンジン、MCPの119ツールと通信、COM定義、セットアップの入力・版・ハッシュを検査します。インストールやCAD実機検証はこの自動検査には含みません。

既存の開発ビルドでのSolid Edge 2026実機検証（2026-10-23）では、20部品の凸モデルの取り込み、材質による7.833 kgの質量取得、台とワークの干渉なし、0～4秒の全190組の連続経路確認、チャートの保存・再接続による復元を確認済みです。今回の配布版のインストール後の実機検証は未実施です。

曲面・凹形状・空洞・入れ子アセンブリ、複数材質、CAD慣性テンソルの直接指定、実アセンブリからの機構・グリッパーの動作推定は未対応です。物理エンジンはBepuPhysics 2.5.0-beta.33です。NC加工・切削・TCP・PLC接続・負荷計算には対応しません。
