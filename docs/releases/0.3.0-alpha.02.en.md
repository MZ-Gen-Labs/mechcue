# MechCue 0.3.0-alpha.02

<!-- mechcue-docs-language -->
[日本語](0.3.0-alpha.02.md) | [English](0.3.0-alpha.02.en.md) | [Documentation](../INDEX.en.md)

Adds alert control and remeshing through MCP. **Draft/Prerelease only.**

- Read DisplayAlerts with `solidedge_get_automation_settings`; change it with `solidedge_set_display_alerts` in edit mode.
- `suppressAlerts=true` affects only the call and restores settings on success/error.
- `regenerateMesh=true` replaces the selected study's mesh, retaining geometry/material/fixing/loads and invalidating old results.
- Correct mesh-size native units to metres. Regenerate alpha.01 meshes whose displayed setting may not match actual density.
- Redisplay/reactivate already loaded parts if native mesh deletion closes their windows; recheck target/error state after solving rather than recording another document's result as success.

Example: `meshSizeMm=2, regenerateMesh=true, suppressAlerts=true`. Update MCP and reconnect.

Solid Edge 2026 with200×30×10 mm steel/200 N produced98778 tetrahedra at2 mm versus141 coarse elements, about81.10 MPa maximum stress and1.059 mm displacement; results were saved. Alerts on/off and success/input-error restoration passed. Solver/license dialogs are not universally suppressed. See [Simulation](../SIMULATION_AUTOMATION.en.md).
