# MechCue 0.3.0-alpha.04

<!-- mechcue-docs-language -->
[日本語](0.3.0-alpha.04.md) | [English](0.3.0-alpha.04.en.md) | [Documentation](../INDEX.en.md)

Adds the MCP traffic monitor to tray settings. **Draft/Prerelease only.**

Shows request/notification/result time, direction, PID, tool, success/failure/duration and selected argument/result JSON. Provides search, pause, clear display, JSON Lines save, persisted Always on top and Record traffic. It reads separate local files without changing stdio; logging failures do not stop MCP.

Update including MCP, reconnect the AI client and open the monitor in tray settings. Limits:500 displayed events, about4 MiB×three generations per process, periodic64-file/seven-day cleanup. Over256 KiB messages truncate monitor detail only. Logs contain arguments/results/paths; review before sharing.

Two real MCP processes verified matching JSON, separation of equal request IDs, split UTF-8 input, failure/duration, live record toggles and operation with unwritable logging. UI search/detail/pause/resume/topmost persistence passed. CAD behavior did not change.
