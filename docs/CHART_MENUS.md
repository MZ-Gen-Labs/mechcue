# チャートの操作欄

再生、時刻、速度、反映、干渉、反復、自動、編集／表示、元に戻す、やり直し、最小表示は上部で直接操作できます。独立版にも必要な操作は残しています。フル表示ではメニューボタンの幅を絞り、操作欄を1行に配置します。「表示」はグラフ編集を禁止する従来の「動作確認」と同じモードです。

- CAD：接続、基準状態に戻す、切断。
- データ：CAD保存、JSONの読み込み／保存、CSV・Excelの読み込み／書き出し、概略軸の取り込み。
- 表示：フル／最小切り替え、機構・設定・点のパネル表示、CADを最大化して9か所へ配置。
- 設定：AI接続、言語、使い方、ログフォルダー。

「自動」は「反復」の後にあり、フル／最小の両方で操作できます。オンの場合は再生開始時に反映をオンにし、開始姿勢も検証してから再生します。エラーで反映または動作が停止した場合は自動もオフになります。表示・動作パターンの切り替えでは自動を保持しますが、起動時、新しい設定の読み込み、接続、切断、基準状態へ戻す操作ではオフです。自動の選択は保存しません。MCP・アドインからの再生にも同じ設定を適用します。

動作パターンの削除は、チャート上部のパターン選択欄の右にある「⋯」メニューの「削除」です。最後の1つは残します。

通常の機構の削除は、左の機構一覧下部の「削除」です。初期機構も対象です。選択機構を全パターンから削除し、登録先は基準状態に戻して解除します。CAD部品は削除しません。誤操作を避ける確認ダイアログがあります。最後の1機構は残します。連動する概略軸の個別削除は対応していません。

機構一覧は名前をドラッグして並べ替えます。青い挿入線の位置で離すと移動し、Escまたは一覧の外で離すと取り消します。チェック欄は表示チェック専用です。駆動先、各動作パターン、選択、チェック状態を保持し、並び順も保存します。入力途中の値は移動前に確定します。
