## ファイルを開く・閉じるルール

MCPサーバーは初期接続の`instructions`に次の指針を送る。能力診断でも同じルールを取得できる。クライアントがこれを利用するかはクライアント実装に依存するため、ツールの説明にも明記した。

1. 元の作業文書と、ユーザーが既に開いていた文書を記録する。
2. アセンブリ作業で作成/開いた一時作業部品・サブアセンブリは、編集完了後に健全性を確認して保存する。
3. 継続作業に不要になった文書は`solidedge_close_document(expectedDocument, returnDocument)`で閉じ、作業アセンブリへ戻る。
4. 既存のユーザー文書は許可なく閉じない。未保存変更を破棄したり、無関係な文書をまとめて保存したり、終了処理としてSolid Edge全体を終了しない。
5. MechCueの動作設定を編集した場合は、閉じる前に`mechcue_save_document`で保存完了を確認する。

閉鎖ツールはアクティブ文書ガードを使い、保存済みの実在ファイルのみ受け付ける。対象と参照子孫がdirtyなら拒否する。戻り先は既に開いている別文書に限定。閉鎖後に対象のウィンドウが残っていないことを確認し、参照として残っているかも返す。保存・変更破棄は行わない。

新しい詳細アセンブリ生成ツールは、生成した各サブアセンブリを保存後に自動で閉じ、最後の詳細アセンブリを開いた状態にする。部分失敗時は未保存文書を消さず、確認してから続行する。

## 継続する不足機能

専用穴・ねじ・座ぐり・パターンと穴表、面取り、寸法付きスケッチ、実面/円筒による組立拘束と自由度、許容接触ペア・最小すきま・連続掃引検査、組立質量/重心/慣性と軸負荷、汎用バッチ実行・途中再開は今後の項目。今回の丸めや離散姿勢検査でこれらを代用したとは扱わない。

新ツールを既存接続で使うには、更新したMCPバイナリへの切替と接続の再起動が必要。現在動作中の旧サーバーへソース変更だけで機能は追加されない。
