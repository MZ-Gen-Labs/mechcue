## 翻訳の更新

文書を変更したら対応する言語版も更新してください。通常は日本語を `.md`、英語を `.en.md` とします。元から英語の第三者情報とアイコン資料は `.md` を英語として残し、日本語を `.ja.md` に用意しています。コード上の識別子や設定キーは翻訳しません。

新しい公開文書は両言語版と、この一覧への両方のリンクを追加します。文書内のリンクは、対応版がある場合は読んでいる言語へつなぎます。`LICENSE` と開発エージェント用の指示ファイルは元の内容を維持します。不具合報告テンプレートは日英併記です。

```powershell
python scripts/Check-Documentation.py
```

この検査は対応版・相互リンク・一覧への掲載・ローカルリンクを確認します。翻訳内容の正確さや外部サイトの到達性を保証するものではありません。
