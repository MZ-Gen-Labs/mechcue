# 概念から詳細へのMCPワークフロー改善

2026-10-02。インストール後の検証で得られた５件に対するソース修正。リリース番号変更、インストーラ作成、既存インストールの更新は含まない。

| 課題 | 実装した対応 |
|---|---|
| 干渉ゼロでネイティブレポートが生成されずエラー | ネイティブ解析がclearの場合だけMechCue要約を作成。生成元・生成有無を明示。それ以外のファイル不在は解析結果と警告を返し、不明をclearへ変換しない。 |
| 同名フィーチャーで形状作成後に命名エラー | 形状作成前に既存名を検査。作成後の失敗は途中成功を明示し、一覧確認前の再実行を避ける。 |
| 概念から詳細への一括移行・保存・閉じ直しが未対応 | 保存済み設定読取、アドイン経由の一括移行・明示保存、Dirty文書を拒否する再オープンをMCPへ追加。 |
| 初期サンプルが軸取込後も残る | 任意の未割当てグラフ非表示。既定動作を維持し、削除はしない。割当て済み・未解決割当ては保持する。 |
| 表示操作でDirtyが変わる場合がある | 表示設定・画像出力に操作前後のDirty状態を追加。自動保存はしない。 |

## 移行の条件

元と詳細側で軸ID・順序・階層・種類・方向・範囲・原点が一致すること。詳細側マニフェストが、アクティブな詳細アセンブリの直下にある部品／剛体サブアセンブリへ一意に対応し、元の参照姿勢で配置されていること。

グラフID、動作パターンID、全キーフレーム、元の参照軸値を維持する。移行先に既存設定・割当てがある場合、元に概略軸以外のCAD割当てがある場合、グラフ値が軸範囲を超える場合は拒否する。移行は画面にロードする操作であり、別の明示保存が必要。復元途中の警告は途中成功として返し、安易な再実行を防ぐ。

## 検証

- MechCue本体、MCP、Solid Edgeアドインのビルド成功。
- 自動テスト：干渉ゼロ要約、未完了・未知状態をclearとしないこと、同名拒否、移行時の全ID・動作・キー保持、軸定義不一致・範囲外拒否。
- 画面連携テスト：模擬Solid Edge文書で、MCP要求の取り込み／移行／保存処理を実行。未割当てサンプル非表示、再取込不変、４軸復元、複数動作保持、重複移行拒否、埋込設定への保存を確認。既存画面・動作管理の検証も成功。
- stdio MCP統合テスト：70ツール、読取属性、操作権限、セッション分離、既存グラフ編集・動作切替の回帰確認。
- 実機検証は接続時点でSolid Edgeが起動しておらず、`MK_E_UNAVAILABLE`となったため未完了。実機用の複製文書テスト `scripts/Test-McpWorkflowFixes.py` を用意した。ネイティブの同名拒否・干渉ゼロレポート・表示Dirty・再オープンは実機で再確認が必要。

実機で新しい移行・保存・取込オプションを使用するには、MCPだけでなく改修版MechCueアドイン本体も更新する必要がある。古いアドインは新しい要求に対応しない。更新後はMCPの接続も再起動する。

操作手順と引数は `Mcp/README.md` を参照。
