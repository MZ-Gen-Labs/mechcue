# 3DモデルへのPMI作成

<!-- mechcue-docs-language -->
[日本語](PMI_AUTOMATION.md) | [English](PMI_AUTOMATION.en.md) | [文書一覧](INDEX.md)

図面を作らず、Solid Edgeの部品・アセンブリモデルに関連付けられた参照寸法を追加します。PMIは対象の`.par`または`.asm`ファイル内に保存され、専用モデルビューで表示方向と寸法の表示を切り替えられます。部品PMIは0.2.0-alpha.11から、アセンブリPMIは0.3.2-alpha.01の更新版から対応しています。

## 操作例

MCP設定のタスクトレイで「作成・編集も許可」を選び、AIに次のように依頼します。

- 「開いている部品に、外形と穴径・穴位置のPMIを配置して」
- 「開いているアセンブリに、全体の外形と対応する円形部のPMIを追加して」
- 「外形寸法だけ3Dモデルに追加して」
- 「PMIの一覧を確認して、厚さを見るモデルビューに切り替えて」

AIは`solidedge_get_document`で対象を確認し、取得した`fullName`を`expectedDocument`に渡します。自動保存はしません。生成結果の`warnings`、寸法値、配置を確認し、必要なら`solidedge_save_document`で保存してください。元のモデルを残したい場合は、先に新しいパスへコピーを保存してから作成します。

| MCPツール | 用途 |
|---|---|
| `solidedge_auto_pmi` | 主要寸法と、必要なPMIモデルビューを作成 |
| `solidedge_list_pmi` | 寸法値・参照状態・表示状態・モデルビューの一覧 |
| `solidedge_show_pmi_view` | 一覧にある名前を指定してモデルビューを適用 |
| `solidedge_add_pmi_distance` | アセンブリの2つの部品の間に距離PMIを1つ追加（動く部品の位置・すきま・高さ） |

`solidedge_auto_pmi`の設定：

- `dimensionMode="features"`：軸方向の外形、閉じた円の径・中心位置、直交段差、対応する傾斜角。
- `dimensionMode="overall"`：軸方向の外形のみ。円柱の径は`features`で作成します。
- `maxDimensions=30`：今回追加する寸法数の上限。3～100を指定可能。
- `createModelViews=true`：寸法を置いた平面ごとに`MechCue PMI XY`、`XZ`、`YZ`を作成。完了時は最初のビューを適用。
- `recreateGenerated=false`：`true`にすると、このツールが生成した寸法（外形・径・穴位置・段差・角度）を削除してから作り直し、`removedGenerated`に返します。ユーザー作成のPMIと距離PMIは残します。以前のバージョンで作成し、作成時の値のまま固まったアセンブリPMIの修正に使います。

一覧の`valueNative`は距離がm、角度がradです。作成結果の`added`はmm・度で返します。寸法は形状に関連付けた**参照寸法**で、形状を駆動する拘束にはしません。

### アセンブリを動かす場合

Solid Edge 2026では、APIの`AddDimension`で作成したアセンブリPMIは、そのままだと**2番目の参照先の部品が動いても寸法点・値が作成時の状態のまま**になります（1番目の参照先の移動には追従）。実頂点・円形辺のどちらの参照でも発生し、保存だけでは解消しません。保存済みアセンブリを開き直すか、寸法を保存データから再構築すると追従します。手動のスマート寸法はこの問題を起こしません。

MechCueは各寸法の`AddDimension`直後に、その作成ステップだけを「元に戻す→やり直し」して寸法を再構築します（結果の`added[].motionRebuilt=true`）。Solid Edgeが寸法を記録から再生成するため、開き直しと同じように依存関係が登録され、以後は移動中に`UpdateStatus`や`UpdateAll`を呼ばずに追従します。元に戻す対象が新しい寸法だけであることをKeyと寸法数で確認し、別の操作を戻した場合はやり直しで復元したうえで`motionRebuilt=false`と警告を返します。

`motionRebuilt=false`の寸法と、この修正より前に作成したアセンブリPMIは、作成時の値を保持している場合があります。その場合は`solidedge_auto_pmi`を`recreateGenerated=true`で再実行するか、未保存のMechCueグラフ・設定を`mechcue_save_document`、アセンブリを`solidedge_save_document`で保存して`solidedge_reopen_document`で開き直し、`solidedge_open_mechcue`で再接続します。作成処理は自動保存・自動閉鎖を行いません。結果の`motionFollowVerified=false`は、実際の動作確認をまだ行っていないことを示します。

位置・隙間・高さの寸法値は動きに合わせて変わり、剛体の長さ・幅・厚さは同じ値のまま配置が追従します。手動PMIは削除・再作成しません。

### 動く部品の位置・高さを測る

`solidedge_add_pmi_distance`は、2つの部品の点の間の距離を、指定した方向で1つ作成します。テーブル位置、工具先端の高さ、部品間のすきまなど、動きに合わせて値が変わる寸法に使います。

| 引数 | 内容 |
|---|---|
| `fromPart`／`toPart` | 最上位の部品番号（1から）、または部品名。入れ子の部品は`サブアセンブリ名/部品名`のように`/`で区切ります。名前は`solidedge_get_assembly_tree`で確認できます |
| `fromPoint`／`toPoint` | `vertex:min,min,max`：部品の頂点のうち、X・Y・Zの範囲の最小／中央／最大の角に最も近い頂点。`circle:zmin`：指定軸の座標が最小（`max`なら最大）の閉じた円形辺の中心。工具先端は`circle:zmin`です |
| `axis` | 測定するワールド方向`X`／`Y`／`Z` |
| `plane` | `auto`（X・Y→XY、Z→XZ）または`XY`／`XZ`／`YZ`。測定方向を含む平面に限ります |
| `lineOffsetMm` | `0`なら、両方の点の外側に、同じ平面の距離PMIごとに1段ずつずらして配置します。0以外は、1点目からの平面上の符号付きオフセットです |
| `id`／`replace` | MechCueのPMI ID。同じIDがあれば拒否し、`replace=true`のときだけ作り直します |
| `addToModelView` | `MechCue PMI <平面>`のモデルビューへ登録します。ビューの適用はしません |

例：「ベース底面から工具先端までの高さ」は`fromPart="base"`、`fromPoint="vertex:min,min,min"`、`toPart="tool"`、`toPoint="circle:zmin"`、`axis="Z"`です。作成した寸法も作成直後に再構築し（`motionRebuilt=true`）、値が意図した距離と一致することを確かめてからIDを付けます。

### 寸法の向きの確認

直線寸法は、水平・垂直の向きを設定したあとに値を確かめます。値が合わない場合は、もう一方の向きを1回だけ試し、合った場合は`orientationFallback=true`を返します。どちらでも合わなければ、その寸法を作らず警告を返します。調査中のアセンブリでは、斜めの位置関係にある2点の寸法で向きが入れ替わる現象がありましたが、原因は特定できておらず、最終の検証では再現していません。

## 配置と既存PMI

直線寸法は各モデル平面の下側・左側に、短い寸法から内側、長い寸法を外側に並べます。既存のMechCue寸法は識別属性で再利用し、繰り返して同じ寸法を追加しません。ユーザー作成の寸法は削除・並べ替えしません。新しいモデルビューへの表示登録は生成寸法を中心に行い、元のPMI本体を削除しません。

部品配置・形状を変更した後は`solidedge_auto_pmi`を再実行すると、既存の生成寸法をネイティブの参照寸法更新APIで再計算し、`updated`に返します。関連先が現在の意図した寸法と一致しなくなった場合は、既存寸法を削除・置換せず警告します。一覧取得だけでは更新を実行しません。

Solid EdgeのAPIは、PMIのないモデルで最初にPMIへアクセスすると内部のPMI領域を初期化し、未保存状態になる場合があります。一覧取得でも発生し、`nativePmiInitialized=true`で返します。形状は変更せず、未保存フラグを勝手に解除したり自動保存したりしません。

アセンブリでは各部品の辺・頂点をアセンブリ階層に沿ったネイティブ参照へ変換し、移動・回転を反映してルートアセンブリに寸法を追加します。同じ部品・サブアセンブリの複数配置にも対応します。構成部品に寸法を追加したり、自動保存したりしません。Solid Edgeの注釈初期化・モデルビュー適用・図面表示が子の表示状態を未保存扱いにすることがあります。形状変更や子の保存を意味するものではなく、未保存状態を自動解除しません。

## 現段階の対応範囲

- Solid Edge 2026、単一ボディの部品`.par`とアセンブリ`.asm`。単独の板金・複数ボディ部品は対象外。アセンブリの構成部品は`.par`/`.psm`のロード済みソリッドを使用。
- アセンブリは最大16階層、1000配置、対応形状要素10万個。可変部品・可変サブアセンブリ、簡略表示、アセンブリ側の形状置換、スケール変換は対象外で、寸法生成前に停止。
- アセンブリ外形は関連付け可能な頂点・円中心の寸法幅とソリッドの保守的な範囲を照合します。曲面の端点や斜め配置で外形を正しく関連付けられない方向は警告して省略し、近似外形寸法を作りません。円径など対応する形状寸法は作成可能。
- グローバルXY/XZ/YZ基準平面に沿った主要寸法。任意方向の最適注釈平面は未対応。
- 直線辺・閉じた円形辺を使用。自由曲面、楕円、部分円弧、全フィーチャーの認識は未対応。
- 同じ径の円は同一平面につき代表の径寸法を作成。中心位置は同じ座標を重複させません。穴/外周円の製造上の意味までは判定しません。
- 各平面で円の中心は最大8箇所、段差は各方向の代表、傾斜角は代表1箇所。すべての製造寸法を網羅するものではありません。
- 公差、幾何公差、データム、表面粗さ、断面注釈、3D PDFの出力は未対応。
- 形状変更で辺が削除・入れ替わった場合、既存PMIの関連切れや古い識別属性は自動修復しません。Solid Edgeで参照状態を確認してください。
- 個別作成に失敗した寸法は削除して`warnings`に返し、作成できた寸法は残します。モデル全体の自動ロールバックは行いません。

## 実機検証

`scripts/Test-PmiNative.py`はMCP経由で新規の穴付き板・円柱・段差・傾斜部品を作成し、実際のPMI値、参照状態、ビュー切り替え、保存、重複防止、形状フィーチャーの維持を確認します。Solid Edgeが起動済みで、トレイ設定が作成・編集許可のときに実行できます。出力先は新しいフォルダーを指定してください。

```powershell
python scripts/Test-PmiNative.py --mcp artifacts/0.2.0-alpha.11/mcp/MechCue.Mcp.exe --output artifacts/pmi-test
```

CIではSolid EdgeなしでMCPツール公開・アクセス制御・引数検証と、両版・インストーラーのビルドを確認します。

`scripts/Test-AssemblyPmiNative.py`は移動・回転・同一部品の複数配置・入れ子アセンブリの関連付きPMI、重複防止、モデルビュー切り替え、円径、構成ファイルの維持、既存部品PMIとアセンブリ図面の4ビューを実機で確認します。ユーザーの元のモデルを記録し、新しい検証ファイルのみ作成して、完了した検証ウィンドウを閉じて元のモデルへ戻ります。
