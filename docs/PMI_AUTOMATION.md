# 3DモデルへのPMI作成（0.2.0-alpha.11）

図面を作らず、Solid Edgeの部品モデルに関連付けられた参照寸法を追加します。PMIは`.par`ファイル内に保存され、専用モデルビューで表示方向と寸法の表示を切り替えられます。

## 操作例

MCP設定のタスクトレイで「作成・編集も許可」を選び、AIに次のように依頼します。

- 「開いている部品に、外形と穴径・穴位置のPMIを配置して」
- 「外形寸法だけ3Dモデルに追加して」
- 「PMIの一覧を確認して、厚さを見るモデルビューに切り替えて」

AIは`solidedge_get_document`で対象を確認し、取得した`fullName`を`expectedDocument`に渡します。自動保存はしません。生成結果の`warnings`、寸法値、配置を確認し、必要なら`solidedge_save_document`で保存してください。元のモデルを残したい場合は、先に新しいパスへコピーを保存してから作成します。

| MCPツール | 用途 |
|---|---|
| `solidedge_auto_pmi` | 主要寸法と、必要なPMIモデルビューを作成 |
| `solidedge_list_pmi` | 寸法値・参照状態・表示状態・モデルビューの一覧 |
| `solidedge_show_pmi_view` | 一覧にある名前を指定してモデルビューを適用 |

`solidedge_auto_pmi`の設定：

- `dimensionMode="features"`：軸方向の外形、閉じた円の径・中心位置、直交段差、対応する傾斜角。
- `dimensionMode="overall"`：軸方向の外形のみ。円柱の径は`features`で作成します。
- `maxDimensions=30`：今回追加する寸法数の上限。3～100を指定可能。
- `createModelViews=true`：寸法を置いた平面ごとに`MechCue PMI XY`、`XZ`、`YZ`を作成。完了時は最初のビューを適用。

一覧の`valueNative`は距離がm、角度がradです。作成結果の`added`はmm・度で返します。寸法は形状に関連付けた**参照寸法**で、形状を駆動する拘束にはしません。

## 配置と既存PMI

直線寸法は各モデル平面の下側・左側に、短い寸法から内側、長い寸法を外側に並べます。既存のMechCue寸法は識別属性で再利用し、繰り返して同じ寸法を追加しません。ユーザー作成の寸法は削除・並べ替えしません。新しいモデルビューへの表示登録は生成寸法を中心に行い、元のPMI本体を削除しません。

Solid EdgeのAPIは、PMIのない部品で最初にPMIへアクセスすると内部のPMI領域を初期化し、未保存状態になる場合があります。一覧取得でも発生し、`nativePmiInitialized=true`で返します。形状は変更せず、未保存フラグを勝手に解除したり自動保存したりしません。

## 現段階の対応範囲

- Solid Edge 2026、単一ボディの部品`.par`。アセンブリ・板金・複数ボディは対象外。
- グローバルXY/XZ/YZ基準平面に沿った主要寸法。任意方向の最適注釈平面は未対応。
- 直線辺・閉じた円形辺を使用。自由曲面、楕円、部分円弧、全フィーチャーの認識は未対応。
- 同じ径の円は同一平面につき代表の径寸法を作成。中心位置は同じ座標を重複させません。穴/外周円の製造上の意味までは判定しません。
- 各平面で円の中心は最大8箇所、段差は各方向の代表、傾斜角は代表1箇所。すべての製造寸法を網羅するものではありません。
- 公差、幾何公差、データム、表面粗さ、断面注釈、3D PDFの出力は未対応。
- 形状変更で辺が削除・入れ替わった場合、既存PMIの関連切れや古い識別属性は自動修復しません。Solid Edgeで参照状態を確認してください。
- 個別作成に失敗した寸法は削除して`warnings`に返し、作成できた寸法は残します。モデル全体の自動ロールバックは行いません。

## 実機検証

`scripts/Test-PmiNative.py`はMCP経由で新規の穴付き板・円柱・段差・傾斜部品を作成し、実際のPMI値、参照状態、ビュー切り替え、保存、重複防止、形状フィーチャーの維持を確認します。Solid Edgeが起動済みで、トレイ設定が作成・編集許可のときに実行できます。出力先は新しいフォルダーを指定してください。

```powershell
python scripts/Test-PmiNative.py --mcp artifacts/0.2.0-alpha.11/mcp/MechCue.Mcp.exe --output artifacts/pmi-test
```

CIではSolid EdgeなしでMCPツール公開・アクセス制御・引数検証と、両版・インストーラーのビルドを確認します。
