# 製品名と近い製品の調査

2026-09-30。採用名：**MechCue（メックキュー）**。
Mech（機構）とCue（合図）。時間に沿って機構へ動作を与える意味で、将来のPLC連携にも合います。

| 製品 | 近い機能 |
|---|---|
| [Solid Edge](https://solidedge.siemens.com/en/solutions/products/3d-design/assembly-modeling-and-management/) | モーター、タイムライン、アニメーション |
| [Visual Components](https://www.visualcomponents.com/products/robot-offline-programming/) | 3D生産シミュレーション、PLC・ロボット接続 |
| [Emulate3D](https://www.rockwellautomation.com/en-us/products/software/factorytalk/designsuite/emulate3d-digital-twin.html) | デジタルツイン、仮想試運転 |

完全に同等ではなく、近接分野の製品です。このツールは「変位グラフの直接編集とSolid Edgeへの割り当て」に集中します。
現在はPLC接続・物理解析を備えた仮想試運転の代替とは位置付けません。

一般Web検索で`"MechCue"`、`"MechCue" software CAD simulation`、`"MechCue" GitHub`、
`"メックキュー"`を確認した範囲では同名のソフトウェア製品は見つかりませんでした。
KineTraceとMotionLoomには既存ソフトウェアがあり、採用しませんでした。
検索範囲の確認であり、商標・未公開製品・ドメイン取得可能性は未確認です。
Siemens公式製品と誤認させる説明は使用しません。
