# MCPでの反映設定と干渉検査

## 操作

`mechcue_set_playback_options` で、接続したアセンブリとセッションを指定し、
`applyToCad`（Solid Edgeへの反映）と `stopOnInterference`（干渉したら停止）を変更する。
両方を同時に指定することも、片方だけを指定することもできる。
省略した設定は保持する。少なくとも片方が必要。

```json
{
  "expectedDocument": "C:\\work\\concept.asm",
  "sessionId": "選択したセッションID",
  "applyToCad": true,
  "stopOnInterference": true
}
```

この操作は再生を停止して選択を変更するだけで、CADを動かさない。
次の `mechcue_play` または `mechcue_seek` が反映設定に従ってCADを動かす。
Creation/editモードが必要で、文書名が違う場合は変更を拒否する。
干渉設定は `mechcue_save_document` によってパターンとともに保存する。
反映は実行中のセッションに対する設定であり、保存によって次回起動時にONにはしない。

`mechcue_get_state` は `applyToCad`、`stopOnInterference`、`requiredClearanceMm`、
`numericalMarginMm`、`inspectionRunning` を返す。

## 「細分」チェックボックス

通常表示・最小表示とも「自動」の右に「細分」を配置する。既定はON。
この選択は再生・時刻移動時の干渉検査を対象とする。

- ON: 移動量・回転量による検査点の追加と、検査方針に応じた連続区間の細分化を行う。
- OFF: 元のキーフレームと要求された移動先の姿勢を検査し、区間内に追加の検査点を挿入しない。
  再生中は画面更新先の姿勢も検査する。検査した姿勢間の干渉は未確認で、連続区間の保証は付けない。

切り替えると再生を停止する。キーフレームや動作の補間方式は変更しない。
選択はアセンブリへ保存でき、パターン切り替えでも保持する。
この設定を持たない既存ファイルはONとして読み込む。
経路検査画面や明示的なMCP経路検査は、それぞれ指定された検査方針を使用する。

MCPでは `mechcue_set_playback_options` の `subdivideInspection` で切り替え、
`mechcue_get_state` の同名フィールドで確認できる。

## すきまと干渉の違い

要求すきまは部品表面間の最短距離に対する下限で、既定は0 mm。
接触は最短距離0 mmになるが、距離だけで干渉を判定しない。
包含されている物体では境界間の距離が正になることもあるため、
Solid Edgeの干渉解析結果も用いる。
実際の干渉、干渉の可能性、距離不足、解析未完了を「問題なし」にしない。

連続区間には別の数値余裕（既定0.01 mm）がある。
区間の端点が干渉しないだけでは、その間の運動が干渉しないとは限らないので、
相対移動量を差し引いた距離の下限で確認し、必要なら区間を細分化する。

## 長時間処理の対策

保存された形状を検証でき、区間全体の相対移動量が厳密にゼロで、
両端のネイティブ解析が完了して問題なしと判定した組は、同じ形状・相対位置を保つ。
この組の距離の下限には移動の数値余裕を重ねて差し引かない。
これにより、ネイティブ解析では干渉しない静止した接触組を、
0 mmから数値余裕を差し引いた負の下限で繰り返し細分化する経路を防ぐ。
動く組、未保存の形状、干渉・解析未完了の組には適用しない。
意図した接触の対象外登録は自動では行わない。

干渉ONの再生は、検査処理にかかった時間を次の再生区間に足し込まない。
各区間の検査は2秒の処理時間予算を持ち、使い切った場合は未確認として停止し、
開始姿勢へ復元する。タイマーでの停止通知はステータスとログに残し、
モーダルダイアログの確認待ちにしない。

MCPの `check_motion` は、UIスレッド上のCAD呼び出し間で処理を譲る。
10秒の予算を持ち、`mechcue_stop` で協調的に中止できる。
処理中も状態取得とUI応答確認が可能。検査・編集の競合を拒否する。
完了・中止は `mechcue_get_operation` で確認し、中止した残り区間は未確認として残す。
時間予算と中止はネイティブCAD呼び出しの間で確認するもので、
単独のSolid Edge API呼び出し自体を強制的に中断するものではない。

## 検証範囲

回帰テストは設定変更時にCADを動かさないこと、文書ガード、片方の設定保持、
権限、静止接触の距離下限、処理時間超過時の停止と姿勢復元、
協調中止・未確認区間の保持、再生中のモーダル待ち回避を確認する。

修正版でCAD実機の再検証を行うには、更新セットアップの適用、Solid Edgeの再起動、
MCPの再接続が必要。既に旧版で実行中の検査は、ディスク上のDLLを更新しても
修正版の処理には切り替わらない。
