# 経路の自動細分化と干渉検査

2026-10-03 実装。0.3.1-alpha.03 に収録。既配布の 0.3.1-alpha.02 セットアップには含まれません。

## 経路全体の結果をUIで記録する

動作パターン欄の「経路検査」を開きます。「選択経路を検査」は現在の動作、「全動作パターンを検査」は登録済みの動作を順に先頭から終端まで検査します。干渉を検出しても後続の点を確認します。解析失敗・中止・点数超過は未完了として記録し、中止後の未実行パターンも記録します。終了後は元の姿勢・選択経路・グラフに戻り、再生は停止したままです。

動作名、判定、検査区間、実行点数／予定点数、要求すきま、記録時刻を一覧に表示します。下欄では時刻ごとの状況、最小すきま、対象部品、解析エラーを確認できます。「結果をJSON保存」で軸値・最近接点・検査条件も保存できます。再生中の干渉検出とMCPの区間検査も記録し、連続する安全な再生区間は一つの記録にまとめます。

記録はセッション中の直近100件です。一つの再生記録は最大10001点です。終了前に必要な結果をJSON保存してください。結果は検査時点のスナップショットです。CAD形状・配置・駆動先・グラフを変更した後は再検査してください。

## 最小すきまを判定する

「要求すきま [mm]」の0は無効、正数はSolid Edgeの専用 `AssemblyDocument.MinimumDistance` でトップ階層の部品／サブアセンブリの各ペアを測定します。要求より小さい距離をすきま不足とし、最小距離・最も近いペア・最近接点を記録します。最大10000ペアです。計測失敗を安全とは扱いません。再生中の干渉検出にもこの設定を使用します。

サブアセンブリ内部の部品同士のすきまは対象外です。サブアセンブリを開いて別途検査してください。意図した接触の除外は未対応なので、固定接触のあるアセンブリで正の要求値を使うと、その接触もすきま不足になります。

## 部品外形から検査点を増やす

`Occurrence.Range` で現在の部品外形を取得し、原点からの外形の広がり、登録時の部品位置、概略軸の原点オフセット、経路内の直動量から回転半径を見積もります。直動変化量と「半径×回転角（rad）」の合計が「表面移動量の目安 [mm]」を超える区間を細分化します。既定は5 mm。軸変化量による5 mm／1°の条件も維持します。外形を取得できない場合は検査を拒否します。

保守的な外形に基づく見積もりであり、任意の拘束機構の表面移動量の厳密保証ではありません。モデルが原点から遠い場合や大きい場合は点数が増えるため、間隔・点数上限を調整してください。

## MechCueで使う

駆動先と検証経路を設定し、先頭時刻から「干渉検出」を有効にして再生します。更新時刻間のすべてのキーフレームを含め、時間1秒・直動の変化量合計5 mm・回転の変化量合計1°を上限に検査点を追加します。同時に動く軸は、それぞれの変化量の絶対値を合計します。360°の回転や、両端の値が同じ往復動作も途中を確認します。時間カーソルを逆方向に移動する場合も同様です。

初回の姿勢合わせはその姿勢だけを確認します。経路全体を調べるには必ず先頭から終端まで再生してください。終端から先頭へのループ移動は未検証なので、干渉検出を有効にした再生は終端で停止します。

干渉・干渉の可能性・解析失敗では停止し、直前に完了した更新時刻の姿勢へ戻します。検査点数が1更新で5001を超える場合は、動かす前に拒否します。小さい時間区間で実行してください。検査に時間がかかる場合も途中の検査点は省略しません。

## MCPで区間をまとめて検査する

`mechcue_start_operation` の `operation="check_motion"` に以下の `argumentsJson` を指定します。結果は既存の操作結果取得ツールで確認します。

```json
{
  "startTime": 0,
  "endTime": 10,
  "step": 1,
  "adaptive": true,
  "maxLinearStepMm": 5,
  "maxAngularStepDeg": 1,
  "surfaceBased": true,
  "maxSurfaceStepMm": 5,
  "requiredClearanceMm": 0.5,
  "maxSamples": 5001,
  "stopOnInterference": false
}
```

`adaptive` は既定で true。`step` は時間間隔の上限です。`maxSamples` は2〜10001。超過時は移動せずエラーにします。`adaptive=false` は従来の固定時間刻み（最大501点）です。

結果は各時刻の軸値とSolid Edgeの干渉状態・部品情報を含みます。`allSamplesClear=true` に加えて `samplingComplete=true` と `analysisComplete=true` を確認してください。`stopOnInterference=true` で途中停止した場合、後続の時刻は未検査です。解析失敗時は設定にかかわらず中止します。終了後は検査前の姿勢へ戻します。

## 判定の範囲と不足機能

`continuousPathCertified` は常に false です。「検査点で干渉なし」は、検査点間の干渉が存在しない保証ではありません。5 mm・1°は軸の変化量であり、回転軸から離れた部品表面の移動量を直接制限していません。クリアランスが小さい箇所は、上限を小さくして再検査してください。

今後必要な機能は、意図した接触ペアの除外、単一サブアセンブリ内部のすきま検査、拘束機構の回転中心を追跡した厳密な表面移動量評価、掃引形状による連続判定です。

## 検証

- 自己テスト：途中ピーク、360°回転、複数軸同時変化、検査上限、逆方向移動、途中干渉での復元を確認。
- Solid Edge 2026：10 mm角の部品を固定部品の反対側へ移動。両端0秒・1秒の検査は干渉なし、自動細分化は途中の干渉を検出。再生停止と開始姿勢への復元を確認。
- 専用最小距離：20 mmのすきまを21 mmの要求に対して不足と判定。
- 回転原点から1 m離れた実部品：1°の回転で、外形を考慮する設定の方が角度のみより検査点が増えることを確認。
- UI全パターン検査：衝突する経路13/13点、安全な経路3/3点を記録しJSON保存。検査後の選択経路・グラフ保持と元文書の変更状態保持を確認。
- 実機記録：`output/motion-sampling-native-alpha03-08/results.json`、`ui-reports.json`、`ui-results.png`。成功した検証用ファイルは保存して閉じた。途中の診断で残ったテスト専用ファイルも保存して閉じ、元アセンブリの変更状態を保持した。

公式API資料：[専用最小距離](https://support.industrysoftware.automation.siemens.com/trainings/se/107/api/SolidEdgeAssembly~AssemblyDocument~MinimumDistance.html)、[部品外形の取得](https://support.industrysoftware.automation.siemens.com/trainings/se/106/api/SolidEdgeAssembly~Occurrence~Range.html)。Solid Edge 2026で実機検証した。
