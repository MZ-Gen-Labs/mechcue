# モデル以外の残課題の完了記録

対象は、画面配置・Undo/Redoのテスト失敗、異常発見後の部品対ごとの連続検証、固定部品対の測定再利用、自動分割・結果統合。これらを0.3.1-alpha.05で実装した。コミットは `b527a60`。GitHubへの送信・タグ作成・公開・インストールは行っていない。

## 実装

- 画面配置の回帰検証では、バックグラウンドプロセスで変わるアクティブ状態を各入力時に明示するようにし、配置・サイズ・モード・解除と復帰を検証した。Undo/RedoはグローバルなCtrl+Z/Y登録を廃止し、MechCue内のネイティブ子ウィンドウの入力を処理する。文字編集・非アクティブ画面・キー解放ではチャート操作を実行しない。
- 連続区間を部品対ごとに判定し、異常がある組とは独立して他の組を確認する。異常を含む経路全体を安全とはしない。未対応運動の場合も検査点で確認した異常の部品対を記録する。
- 相対運動のない組は1回の検査内で測定を再利用する。共通剛体移動で最小距離点の座標が変わる場合は座標も追従させる。参照文書・ファイル版・保存状態・実姿勢を確認し、形状の変更を検知したら停止する。検査をまたぐ古い結果の再利用は行わない。
- 作業点数や部品対データの上限では作業単位を分けて続行し、区間境界と全部品対の結果を統合する。全体の点数・再評価数・分割深さ・ファイル容量には別の上限を設け、到達や中止を未確認とする。
- 大きな姿勢・区間結果はファイルに退避する。MCPは要約とページ取得、UIは部品名付き判定と先頭詳細、JSON保存は全詳細を出力する。履歴退去・画面終了時には、その記録が所有する退避ファイルを整理する。

共通の仕様はコミット済みの `CONTINUOUS_MOTION_INSPECTION.md` に記録した。

## 検証

Solid Edge 2026の専用モデルで27項目に成功。連続区間・途中衝突・固定組再利用・距離点の追従・独立した部品対証明・未対応運動・自動分割・形状版変更・中止・接触指定・UI一括検査・同時XYZ/A/Cと360度回転・姿勢復元を確認した。証跡は `output/advanced-motion-completion-20261003-03/`。

共通ビルドで、本体セルフテスト、スモークテスト、退避結果の全件出力・MCPページ取得、MCP23項目（102ツール登録確認を含む）、通信監視、更新時終了、COM契約、セットアップの入力・版・ハッシュを確認する。提供用ビルドは `artifacts/0.3.1-alpha.05-delivery/`。

44部品・5パターンの実モデルでも、全初期検査点で解析と姿勢復元が完了し、既知の干渉5組とすきま不足4組を保持した。最新の全可動範囲の結果は328,066バイト（旧269,022,550バイト）。この比較はチャート整理・結果形式・組ごとの集計の違いを含む。証跡は `output/mill5-completion-inspection-20261003-02/`。その時点では `FixedStructure.asm` が未保存状態のため、再利用・連続証明を無効にしていた。工作機械全体の無干渉を証明したものではない。

テスト文書は保存して閉じ、元の `mill5-detail.asm` の姿勢を復元して保存し、MechCue画面を開き直した。現在インストール済みのalpha.04は変更していない。今回のソフト変更を利用するにはalpha.05のセットアップが必要。

## 残る対象

今回挙げたソフト側の4課題は実装済み。モデルの形状・配置による干渉5組とすきま不足4組の解消は別作業。拘束駆動や変形形状など仕様上の未対応対象、明示した接触除外、総予算到達を安全とする機能は追加していない。
