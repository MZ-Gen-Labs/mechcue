# タイムチャートの表示位置

タイムチャートにフォーカスがある状態で `Ctrl+Alt+Shift` と下表の文字キーを押すと、Solid Edgeを最大化し、現在の表示モードと大きさを保って指定位置へ移動します。同じキーを続けて押すと、その位置でフル表示とコンパクト表示を交互に切り替えます。別のキーを押したときは移動だけです。数字キーのショートカットは廃止しました。タイムチャート以外のウィンドウがアクティブなときはキーを登録しません。

| 左 | 中央 | 右 |
| --- | --- | --- |
| U：左上 | I：上中央 | O：右上 |
| J：左中央 | K：中央 | L：右中央 |
| M：左下 | ,：下中央 | .：右下 |

「表示」メニューの「CADを最大化して表示位置を選ぶ」、または最小表示の「▦」ボタンからも選択できます。メニュー操作は繰り返しても移動だけです。配置先はSolid Edgeが表示されているモニターの作業領域です。タスクバーを避け、画面に収まらない場合だけ大きさを補正します。ショートカットでコンパクトに切り替えたときは最小サイズにし、フルに戻したときは切り替え前の大きさを復元します。

手動で位置・大きさ・表示モードを変えた場合やMCP・位置メニューで移動した場合、次のショートカットは移動から始まります。同じキーを続けて押す判定は、前回のショートカットと位置・大きさ・表示モードが一致している間です。キーの押しっぱなしによる連続切り替えは行いません。

手動で変更した位置と大きさ、最大化状態、最小表示の状態は移動・サイズ変更の終了時とウィンドウを閉じたときに保存し、次回表示時に復元します。アドイン版と独立版は別々に保持します。モニターを外した場合や解像度が変わった場合は、表示できる範囲に補正します。

表示モードを切り替える際は再生を停止し、コンパクト表示にする際は編集中の値を確定します。配置だけでは再生を止めません。

メニューの最小表示、編集画面へ戻る、アドインの表示切り替え、パネル表示によるフルへの復帰、ショートカット、前回表示の復元は、同じ描画停止処理を通ります。

再生設定のチェックボックスは、フル・最小表示とも「反映・干渉・反復・自動」の順です。表示切り替え、動作パターン切り替え、CAD保存、駆動先の登録・解除、現在値読み込み、表の読み込み、MCPのグラフ編集ではチェック状態を維持します。操作中のCAD反映だけを一時停止し、処理完了後の再生・時刻操作で反映を再開します。パターンごとの速度は従来どおり復元し、干渉・反復は現在の選択を継続します。新しい接続・設定読み込み、切断、基準状態への復帰、動作エラー時は反映と自動をオフにします。「自動」がオンの場合は再生開始時に反映を有効にします。[操作欄と削除の詳細](CHART_MENUS.md)。

アドインの再生ボタンは大きなアイコンと下側のラベルを使い、既存のリボンにも変更が反映されるようGUI版を更新しています。

## MCP

`mechcue_place_window` の `position` に1～9を指定します。省略時は3（右下）です。タイムチャートがSolid Edgeに接続されている必要があります。複数のタイムチャートが開いている場合は `sessionId` を指定してください。MCP設定の「作成・編集も許可」が必要です。

MCPの番号は従来のテンキー配置のままです。1～3が下段（M/,/.）、4～6が中段（J/K/L）、7～9が上段（U/I/O）に対応します。MCPからは表示モードと大きさを保って移動し、繰り返し呼んでも表示モードを切り替えません。

例：`mechcue_place_window(position=9, sessionId="対象セッションID")`

結果には位置番号、最小表示状態、CADの最大化状態、ウィンドウの座標・大きさとモニターの作業領域を返します。CADの部品姿勢やファイルの保存を操作する機能ではありません。

## 検証方法

検証用ウィンドウと模擬CADで9か所への配置、最大化、位置・大きさの復元、反映設定の維持とネイティブ通知によるキー処理を検査します。表示モード切り替えはWM_SETREDRAWで途中描画を停止し、最終位置・サイズの反映後に描画を再開します。Solid Edge側の描画設定は変更しません。
