MechCue MCP 接続ガイド

MCPサーバーをインストールしました。MCP対応のAIアプリへ登録すると、MechCueのグラフ編集や再生を指示できます。

  1. MechCueを開き、「AI接続」をオンにします。
  2. AIアプリのローカルMCP（stdio）設定に、インストール先のMechCue.Mcp.exeを登録します。通常の場所は次のとおりです。
    C:\Program Files\MechCue\MCP\MechCue.Mcp.exe
    配置先を変更した場合は、実際のパスを指定してください。設定例は同じフォルダーの mcp-config.example.json です。AIアプリにより設定方法は異なります。
  3. 「機構一覧を確認して、1番目の機構の2秒の値を100にして」などと指示します。

MCPを選択してインストールすると、通常のセットアップ完了後とWindowsへのログイン時に、設定アイコンを自動表示します（0.2.0-alpha.10以降）。MCP本体はAIアプリが起動します。「Solid Edgeアクセスなし」「読み取り・選択のみ」「作成・編集も許可」から選びます。設定は次の操作から反映され、MCPの再起動や起動引数の変更は不要です。スタートメニューの「MechCue MCP」→「MCP設定（タスクトレイ）」からも開けます。すでに実行中のCAD操作は中断しません。

グラフ変更後は再生停止・CAD反映オフになります。再生・時刻指定は画面のCAD反映設定に従います。駆動先は維持され、Undoで編集を戻せます。

サーバーはAIアプリが起動します。通常はEXEをダブルクリックする必要はありません。削除はWindowsのアプリ一覧からMechCueをアンインストールします。

詳細なガイド ／ プロジェクト

English

Enable AI access in MechCue, then register the installed MechCue.Mcp.exe as a local stdio MCP server in your AI app. Use the MechCue MCP tray icon to choose No Solid Edge access, Read/select only, or Allow creation/editing. Changes apply to subsequent calls without restarting MCP. The controller can also be opened from Start → MechCue MCP → MCP settings. The example configuration uses the default install path; adjust it if needed. The AI app starts the server. Uninstall MechCue to remove the installed MCP component.
