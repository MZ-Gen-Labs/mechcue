# アドインのアイコン資源

<!-- mechcue-docs-language -->
[日本語](README.ja.md) | [English](README.md) | [文書一覧](../../docs/INDEX.md)

`MechCue.res` は全41アクションIDの独自ビットマップと、一時停止の追加アイコン（511～514）を含みます。停止は内部処理・MCP互換用に残していますが、リボンには表示しません。各セットは `101+10*n`（16pxカラー）、`102+10*n`（32pxカラー）、`103+10*n`（16px単色）、`104+10*n`（32px単色）です。

`Build-Icons.py` はPythonとPillowでMITライセンスの画像を再生成します。コミット済みの `.res` をアドインDLLへ埋め込むため、ビルド・導入時にPythonやリソースコンパイラーは不要です。`ComContractCheck` がすべてのビットマップセットを検査します。

Solid Edge 2026ではマゼンタの透過色が見えてしまったため、カラーアイコンには白背景を使います。アンチエイリアスも白背景へ合成して紫色の縁を防ぎます。GUI版9でキャッシュされた画像を再読み込みします。
