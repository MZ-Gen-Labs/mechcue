MechCue.res contains separate bitmap resources for each of seven commands. Each command uses four resources: 101+10*n (16px color), 102+10*n (32px color), 103+10*n (16px monochrome), 104+10*n (32px monochrome). Commands: open, play, stop, maximize, minimize, compact, save. Each command is registered separately with SetAddInInfoEx, then its large icon/caption button is added.

Build-Icons.py regenerates the MIT-licensed original artwork using Python and Pillow. The checked-in .res is embedded in the add-in DLL; build/install requires no Python or resource compiler. ComContractCheck checks all 28 bitmaps.
